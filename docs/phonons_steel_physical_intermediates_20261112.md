# 声子与钢的 KAN 学到了哪些物理中间量

2026-11-12。声子沿用正式五折模型的既有分析。钢使用 396 个候选特征、按内层训练集 SHAP 排名前 50 筛选的最新正式实验。本文的“读出 R²”衡量用隐藏激活恢复指定物理量的准确度。模型本身的预测误差另以 cm⁻¹ 或 MPa 表示。

## 第一个任务 · 声子

任务是从晶体结构预测声子态密度的最后一个峰。正式 MM（matminer 描述符）+ MatterVial KAN 的第一层反复出现一个**几何尺度方向**。它同时反映平均键长、每原子体积及体积对应的逆长度。三个量描述的几何信息有重叠。[Matbench 数据定义](https://hackingmaterials.lbl.gov/matminer/dataset_summary.html#matbench-phonons) · [正式声子分析](formal_phonons_interpretability_20261106.md)

| 第一层对应量 | KAN 单节点读出 R² | 五折各自达到强对应的成员比例 |
| --- | ---: | --- |
| 平均键长 | 0.716 | 100%、90%、94%、100%、98% |
| 每原子体积 | 0.697 | 96%、94%、78%、96%、84% |
| 每原子体积的负三分之一次方 | 0.706 | 96%、86%、90%、84%、98% |

以预先固定的第 0 折、第 0 个成员为例，第一层节点 `h[29]` 每增加 1，训练标定的平均键长减少 0.173 Å，每原子体积减少 3.598 Å³。这两条标定在 253 个留出晶体上的 R² 分别为 0.780 和 0.788。把各成员的键长对应节点替换成各自训练均值后，声子预测 MAE 平均增加 11.51 cm⁻¹，五折均变差。体积对应节点的增量为 9.10 cm⁻¹，五折也均变差。节点可能同时携带多种几何信息，两项增量不能相加。

深层仍能读出平均键长和每原子体积，增强 KAN 的整层读出 R² 为 0.805、0.809，对应 MLP 为 0.743、0.724。MLP 第一层也有稳定的键长和逆长度对应。质量相关量的架构优势随输入和读出方式变化。当前证据支持几何信息的保留，模态有效质量与力常数的识别还需要本征矢或动力学矩阵。[声子读出复核](../benchmarks/formal-phonons-readout-robustness-20261106/interpretation.json) · [Phonopy 动力学矩阵定义](https://phonopy.github.io/phonopy/formulation.html#dynamical-matrix)

项目还做过一个显式物理乘积 KAN。它直接给出平均质量、平均共价半径、半径偏差、平均键长、电负性偏差等具名分量，以及预设的质量与电负性乘积项。后者在十次内层运行中删除后均使 MAE 变差，平均增加 7.75 cm⁻¹。这个分解属于 217 参数的小模型。与钢的主对照采用上面的正式预测器。[物理分量与正式模型的区别](kan_interpretability_review_20261106.md)

## 第二个任务 · 钢的屈服强度

对 312 种钢、五个官方外层折，重放了 250 个冻结 KAN 和 250 个配对 MODNet/MLP 成员。每对成员使用相同的训练样本、选中输入和种子，参数量匹配在 5% 以内。原集成的五折平均 MAE 分别为 **84.963 和 86.438 MPa**，各成员原始预测的最大重放误差为 0.00196 MPa。钢的数据输入只有名义化学组成。[钢数据定义](https://hackingmaterials.lbl.gov/matminer/dataset_summary.html#matbench-steels) · [原钢模型比较](../benchmarks/steel396-shap-top50-kan-20261112/comparison.json)

### 单个原生节点能表达什么

固定第 0 折、第 0 个 KAN 成员后，在训练样本上为铬和镍分别选节点，两次都选到了第一层 `h[5]`。该节点越大，钢样通常越贫铬、越富镍。两条标定直接使用同一个激活，在 63 个留出钢样上验证。

| 量 | 从 `h[5]` 标定的原子百分比 | 留出 R² |
| --- | --- | ---: |
| 铬 | `Cr̂ = 6.6136 − 3.8336 h[5]` | 0.762 |
| 镍 | `Nî = 9.7015 + 3.5040 h[5]` | 0.643 |

这个成员的输入中有 Cr 含量，未直接输入 Ni 含量。重算原生样条边后，Cr 输入边占该节点训练中心化边幅度之和的 3.36%，ROOST 嵌入边合计占 49.8%。这是各边平均绝对幅度的比例。312 种钢中 Cr 与 Ni 的原子百分比相关系数为 −0.820，混合的成分方向因而比“专门测量某一元素的节点”更贴合观察。

250 个 KAN 中有 55 个成员为 Cr 和 Ni 选中同一节点，55 个的标定方向均相反。但即使允许每个成员选择自己的最佳节点，铬的五折强对应率也只有 68%、38%、14%、78%、78%，镍为 74%、40%、24%、74%、48%。扣除模型预测值的线性影响后，示例节点对 Cr、Ni 的偏相关绝对值仍有 0.892、0.804。扣除其他家族描述符的线性影响后降为 0.280、0.290。在钢的 16 个候选量中，两种网络的第一层和深层均没有单节点通过声子任务的五折稳定门槛。

### 多个深层节点能恢复哪些量

| 物理量 | KAN 第一层单节点 R² | KAN 深层三节点 R² | KAN 深层整层 R² | MLP 深层整层 R² | 只用 KAN 强度预测值的 R² |
| --- | ---: | ---: | ---: | ---: | ---: |
| 铬含量 | 0.622 | 0.845 | 0.935 | 0.888 | 0.170 |
| 镍含量 | 0.616 | 0.863 | 0.939 | 0.872 | 0.048 |
| 碳、氮原子百分比之和 | 0.577 | 0.821 | **0.911** | 0.801 | 0.017 |
| 原子尺寸失配 δ | 0.574 | 0.814 | **0.912** | 0.813 | 0.021 |
| Schaeffler 铬当量 | 0.620 | 0.840 | **0.930** | 0.869 | 0.131 |
| Schaeffler 镍当量 | 0.556 | 0.779 | **0.883** | 0.826 | 0.191 |
| 钴含量 | 0.593 | 0.813 | 0.916 | 0.804 | 0.048 |
| 钼含量 | 0.249 | 0.535 | 0.743 | 0.633 | −0.008 |

单节点列取每折 50 个成员 R² 的中位数，再等权平均五折。其余列先平均同折 50 个成员的物理量读出，再算留出 R²、等权平均五折。“三节点”指**每个成员**的三个原生节点。以 Cr 为例，单个成员三节点读出 R² 的折内中位数再平均为 0.735，集成后为 0.845。MLP 采用相同三节点预算时，C+N、δ、铬当量的集成 R² 分别为 0.649、0.652、0.738。Mo 在两种架构的三节点读出中都比 Cr、Ni 难恢复。

**碳氮总量**给出名义成分中两种间隙元素的原子总量。样本中只有 43 种钢具有非零名义 N 含量，单凭 C 就能以 R² 0.980 估计 C+N。把每个成员训练集上由 C 线性预测的部分扣掉，再从深层读出剩余量，留出 R² 仍为 0.534。整层读出 C+N 的平均折 RMSE 为 0.151 个原子百分比点。这个量描述元素库存，实际固溶量还取决于它们在各相中的分配。

**原子尺寸失配 δ**用元素原子分数和 Miracle 半径计算，百分数形式为 `100√[Σ xᵢ(1−rᵢ/r̄)²]`，其中 `r̄ = Σ xᵢrᵢ`。它衡量配方中元素半径的离散程度。73.2% 的 KAN 成员直接选入了 δ 描述符，因此 0.912 主要说明深层保留了这一物理信息。读出误差为 0.300 个百分点。实际局部晶格畸变或固溶强化幅度还需独立测量。[matminer 的尺寸失配定义](https://hackingmaterials.lbl.gov/matminer/matminer.featurizers.composition.html#matminer.featurizers.composition.alloy.YangSolidSolution.compute_delta)

**铬当量和镍当量**是更能检验组合信息的候选。先由原子分数换算质量百分数 `wᵢ = 100 xᵢMᵢ / Σ xⱼMⱼ`，再计算 `Cr_eq = w_Cr + w_Mo + 1.5 w_Si + 0.5 w_Nb` 与 `Ni_eq = w_Ni + 30 w_C + 0.5 w_Mn`。冻结的输入特征中均无这两个当量列。它们原用于不锈钢焊缝的组织图，此处只采用其名义成分坐标。在留出样本上，单由 Cr 或 Ni 原子百分比作线性估计的 R² 分别为 0.904、0.735。从 KAN 深层读出各自剩余部分的 R² 分别为 **0.667、0.819**，表明层内还可读到主元素之外的配方差异。两个当量的整层读出 RMSE 为 1.37、1.61 个质量百分比当量点。[Schaeffler 当量与适用背景](https://pmc.ncbi.nlm.nih.gov/articles/PMC7940414/)

同一固定 KAN 成员有 12 个深层节点。令 `z[j]` 表示末层样条映射之前，第 2 个样条层的第 j 个实际输出，编号从 0 开始。只用三个节点就能写出带物理单位的铬当量估计。

```text
Cr_eq_hat [wt.% 当量] = 11.13949 − 2.16971 z[3] − 4.55254 z[1] − 2.10710 z[10]
```

这条训练标定在本折 63 个留出样本上的 R² 为 0.796。按 ID 固定取该折第一个留出钢样 `mb-steels-003`，由化学组成计算的铬当量为 9.509，三个节点给出 9.433。系数属于这个成员的坐标系。另一折或另一个成员有自己的节点与标定。原网络继续用末层样条把这些节点映射到屈服强度。

### 这些节点在屈服预测中起了多大作用

把第一层 Cr、Ni 对应节点分别换为成员训练均值，钢 KAN 的五折平均 MAE 增加 1.37、1.60 MPa，各有四折变差。随机选一个第一层节点同样替换，平均增加 0.72 MPa。对深层，移除每个成员所选三个节点相对于训练均值的输出贡献，Cr、铬当量、C+N、δ 对应组分别增加 15.62、14.38、12.32、12.05 MPa。随机选三个不同深层节点的对照平均也增加 **12.75 MPa**。八组随机抽取使用同一层和相同节点预算。

因此，可以把铬当量和 C+N 当作从预测网络中可定量读取的成分信息。尤其对 C+N 和 δ，定向删除与随机删除造成相近的平均误差变化，证据不足以将这部分 MPa 归为相应的独立强化贡献。移除节点时也同时改变了它携带的其他信息。

## 两个任务的异同

| 比较项 | 声子 KAN | 钢 KAN |
| --- | --- | --- |
| 容易命名的物理信息 | 晶体的几何尺寸，尤其是键长与每原子体积 | 合金的成分方向与配方组合，尤其是 Cr/Ni、C+N、尺寸失配和 Cr/Ni 当量 |
| 表示集中在哪里 | 第一层单个几何相关节点在五折中重复出现，深层仍保留几何信息 | 个别第一层节点有清楚含义，跨折复现主要体现在多节点读出上 |
| 与 MLP 的关系 | MLP 也有几何相关节点，增强 KAN 的深层键长和体积读出较好 | MLP 第一层的 Cr 单节点 R² 更高（0.785 对 0.622）。钢 KAN 深层整层的 16 个物理量在五折中逐项均高于配对 MLP |
| 物理含义的边界 | 有结构参照，可验证几何尺度。独立模态质量、键刚度缺少直接标签 | 有成分参照，可验证名义配方。晶粒尺度、相分数、析出量、位错密度和加工史均未作为观测量进入该任务 |

两边的隐藏表示都保留了比最终预测标量更丰富的信息，相关量也都可能共用一个节点。钢 KAN 深层平均宽度为 39.8，配对 MLP 为 104.2。用训练集最多四个主成分限制读出维数，C+N 的 R² 仍为 0.755 对 0.608，δ 为 0.745 对 0.616，铬当量为 0.763 对 0.661。跨任务比较的依据是各自的留出读出、跨折成员比例及同任务消融对照，声子与钢的预测误差具有不同物理单位。

一种物理上合理的解释是，声子任务提供了每个晶体的实际结构，可以逐样本核对几何尺度。钢任务中，同一名义配方经不同时效可有不同的析出状态与屈服强度，而现有数据能直接核对的是配方。同一钢种改变时效即改变屈服强度的实验说明了这一信息缺口。两个数据集的样本数（1,265 对 312）、特征库和模型宽度也不同，现有比较不能单独确定跨折差异的成因。[钢的时效与屈服强度实验](https://www.nature.com/articles/s41598-021-93795-4)

## 方法与复核

- 每个钢成员只用其实际拟合过的 199 或 200 个钢样，选择与候选量绝对 Pearson 相关最大的节点，拟合斜率、截距、探针和各项线性控制。每折有 62 或 63 个外层钢样，五折合计覆盖 312 个不同 ID。强对应沿用声子门槛，要求留出 |r| ≥ 0.8 且读出 R² ≥ 0.5，跨折稳定要求每一折至少 70% 成员通过。训练概念标签置乱对照下，KAN 第一层 16 个量的五折平均成员中位 R² 均低于 0。
- 检验的 16 项为 C、C+N、Cr、Ni、Mo、Co、Ti、总非铁原子百分比、理想混合熵除以 R、Yang 尺寸失配、平均共价半径、平均原子质量、平均价电子数、价电子数平均绝对偏差、铬当量与镍当量。所有用作物理参照的原始列均经缺失值检查。成分列为名义原子分数，Schaeffler 公式单独换算为质量百分数。
- KAN 深层取最后一个输出样条层之前的激活，MLP 深层取最后一个非线性隐藏层。整层读出统一使用一个训练 RMS 尺度和固定岭惩罚 0.01。三节点读出是看到单节点结果后增加的探索性检验，按同一岭目标逐次加入使训练目标改善最大的原生节点，固定预算为三。最初无正则三节点拟合在个别 MLP 成员上出现严重外推。例如第 2 折成员 3 的深层节点 151，训练激活范围为 −1 至 −0.99987，在留出的 `mb-steels-081` 上达到 92.92。无正则结果和参数一并保留。两种架构的三节点比较采用同一 0.01 惩罚，并在选点和标定两步都使用它。
- 钢 KAN 原始预测的 15,600 个“成员 × 外层样本”值均未触发 MODNet 的越界替换。MLP 有 41 个值触发，前两折为零，后三折分别为 11、13、17。MLP 原始输出的五折 MAE 为 92.908 MPa，经原流程处理为 86.438 MPa。物理读出使用原始隐藏激活。预测消融表述使用与正式成绩相同的越界规则及成员随机种子，文件同时保留原始输出对应的结果。
- 各折成员来自同一批候选的内层拟合，训练集相互重叠。两项研究都是对已评价模型的事后解释。文中跨折结果描述这些保存模型的表示，架构、隐藏宽度及训练缩放仍会影响数值。
