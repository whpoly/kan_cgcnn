# 物理坐标 KAN：可解释性优先的小规模验证

用户要求：解释残差 KAN 的物理含义，并实际测试更适合后续可解释性分析的实现。2026-10-27。

当前隐藏表示残差 KAN 为 `MODNet(x) + gate × KAN(z(x))`。其中 `z` 是由 36 维隐藏向量经过 Dense 16、LayerNorm、tanh 得到的坐标。这些坐标不对应固定物理量；单条 KAN 曲线的可视化不能直接解释质量、键长或力常数。此前物理分组模块也将四个输出重新混入深层网络，不能直接把模块输出解释为最终预测的物理贡献。

本轮使用具名物理量，直接输出预测或直接加到 MODNet 输出。加性 KAN 的形式为 `b + Σ f_i(x_i)`；乘积 KAN 再加四项 `g_p(x_i) h_p(x_j)`。每个边函数为八个三次 B 样条基函数加一个线性项；输入逐列缩放，禁止跨物理量的 Dense 混合或 LayerNorm。所有函数在内层训练分布上中心化，乘积项也减去训练均值。它给出精确的代数分解，但相关描述符仍导致解释不唯一，不能视为因果分解。

加性结构也属于样条广义加性模型；不能把相同函数类换个 KAN 名字当作创新。乘积结构是参考 MultKAN 思想的自定义 TensorFlow 实现，不冒充直接复现官方 pykan。

## 冻结的比较

| 场景 | 加性 KAN | 等参数 MLP 16→8→1 | 乘积 KAN | 等参数 MLP 16→12→1 |
| --- | ---: | ---: | ---: | ---: |
| 仅 16 个物理输入 | 145 | 145 | 217 | 217 |
| MODNet + 物理残差分支 | 35,799 | 35,799 | 35,871 | 35,871 |

混合模型保留相同的 256 输入、96/72/36/36 主干；分支只看 16 个具名物理量。门控初始为零，因此其初始预测与相同种子的 MODNet 完全一致。全部联合训练；不是在同一训练集上先拟合一个已过拟合模型的残差。门控与所有分支权重都参与计算，无无效参数补数。16 输入独立模型与 256 输入模型的信息量不同，只能在对应 KAN/MLP 配对内部作结构比较。

四个事先指定的乘积项：平均原子质量×平均键长、平均原子质量×平均电负性、平均键长×配位数、平均共价半径×每原子体积。这些是可检验的描述符关系，不声称对应完整力常数或已发现物理规律。平均质量也不等于振动模态的有效质量。

全部复用前轮已审核的五个内层输入，只使用 outer-fold-0 的 1,012 个训练样本；全部 SISSO 排除。不加载外层测试。相同两个基础种子 20261027、20271027，每折加折编号；八个模型×两个种子×五折=80 次。它是新结构探索，两个旧种子不被称为新的独立复核。

学习率固定 0.001，Adam，batch 32，最多 400 轮。目标按当前内层训练集均值和标准差缩放；按内层验证 MAE 早停 patience 40、min_delta 0.05 cm⁻¹；恢复精确最佳验证权重。首轮不加入额外稀疏/平滑惩罚，避免不等调参预算。已有同协议的 MODNet 作为参考，复用结果必须检查其输入和种子一致性。

## 解释性不是只画网络图

每个 KAN 保存原始物理单位上的单变量响应、逐样本精确贡献、乘积边函数和各分量训练均值。逐项删除后重新计算验证误差；该检验反映模型对项的依赖，不代表移除某物理机制的真实后果。

只用训练贡献决定遮蔽：平均绝对贡献小于最大项 5% 的项置零；报告实际保留项数、遮蔽后的验证误差。此操作不重训、不改变参数文件，不能声称已经减少部署模型参数量。

边函数的简式候选固定为常数、线性、二次、三次、log(u)、u^(-1/2)、u^(-1)，其中 u 为按训练参考尺度无量纲化的物理坐标，非正值禁用后三种。仅在内层训练坐标上拟合网络响应，以相对响应标准差 5% 的 RMSE 容差选择最简单函数；达不到则保留样条。验证集用于报告替换后整模型误差和预测偏移，不用于挑选公式。不能把拟合的代理公式自动称为物理定律。

跨折/种子的曲线比较只在各训练分布 5%—95% 区间的交集上进行，并注明数据稀疏区。报告曲线相关性、重要项排序的一致性和 MAE，不能只挑一个最好种子展示。乘积因子的符号/尺度有不唯一性，比较时更应看完整两变量项而非孤立因子。

独立物理模型可解释整个预测；混合模型只能解释物理修正项，其深层主干依然不透明，两个分支也可能学习重复信息。若修正项很小或跨种子不稳定，必须直接报告，不能夸大解释覆盖程度。

## 科学依据和边界

声子频率由质量加权的力常数矩阵决定，质量与局域成键是有物理动机的输入，但本任务是 PhDOS 峰的位置，而不是单一谐振子的频率。因此不预先强制整个数据集服从 `ω ∝ 1/sqrt(mean_mass)` 或某一单调性。

参考：[Phonopy 动力学矩阵](https://phonopy.github.io/phonopy/formulation.html#dynamical-matrix)、[KAN 2.0 原论文](https://arxiv.org/abs/2408.10205)、[pykan 作者实现](https://github.com/KindXiaoming/pykan)。

移除 SISSO 和在训练集内拟合预处理，不能独立证明所有 MatterVial 预训练特征都不存在来源重叠。所有本轮数值仍是反复使用内层验证的探索结果，不能与论文外层 MAE 直接比较。
