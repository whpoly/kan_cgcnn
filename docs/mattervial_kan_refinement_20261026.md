# MatterVial 增强输入下的 KAN 改进方案与验证协议

2026-10-26。用户要求：尝试改善 KAN，实际测试并给出可行方案。输出目录：`benchmarks/mattervial-kan-refinement-20261026`。

## 现有证据与待检验假设

此前 80 次无 SISSO 快筛中，MatterVial 输入相对 MatMiner 在 18/20 个学习率×种子×内层折配对中改善；分组稀疏 KAN 仅在 2/20 个配对中优于等参数 MLP。此结论不要求更换数据或从外层测试挑选配置。

旧 KAN 在学习率 0.001 下的末期训练 MAE 与其他模型接近，但验证误差更高，因此不能把问题简单归结为训练不足。多数模型达到 300 轮上限，且仍有训练误差下降；另一方面训练/验证差距明显，仅增加轮数也可能加重过拟合。此前只保存最后一轮权重，验证最佳轮经常早于最后一轮。

旧物理 KAN 的权重并未全部塌缩为零。稀疏和平滑项的实际代价值得消融，但尚不能断言它们一定过强。物理输入的训练分布覆盖了大部分固定样条区间，因此暂不优先增加网格数。

优先验证两个方向：

1. 去掉物理分组 KAN 的稀疏与平滑正则，检验精度是否被这些约束限制；同时保留原正则版本，只有正则不同。
2. 将一个很小的 KAN 放到 MODNet 学到的低维隐藏表示上，以零初始残差支路修正原预测，使其能够使用增强特征形成的表示。

[pykan 作者的调参建议](https://github.com/KindXiaoming/pykan#Advice-on-hyperparameter-tuning)建议先检查小模型和无正则配置，再按精度/解释性目标逐步调整。这里将其作为待检验的设计依据，不假定它一定适用于 phonons。

## 数据与模型

只读取上一轮已审核的五个内层训练/验证输入文件，每折相同 256 个增强特征。包含此前固定的 16 个物理描述符；全部 SISSO 已排除。输入、样本 ID、预处理拟合范围与文件哈希再次核验。仅使用第一外层折的 1,012 个训练样本，不加载旧模型权重或外层预测/成绩。

| 模型 | 作用 | 总参数量 |
| --- | --- | ---: |
| 增强 MODNet | 新训练协议下同步重跑的基线 | 35,653 |
| 物理分组 MLP | 16→4，配对容量对照 | 36,185 |
| 物理分组 KAN，无正则 | 同样 16→4 的精度候选 | 36,185 |
| 物理分组 KAN，原正则 | 只作正则消融，不参与候选择优 | 36,185 |
| 隐藏表示残差 MLP | 配对容量对照 | 36,391 |
| 隐藏表示残差 KAN | 低维残差精度候选 | 36,391 |

隐藏表示残差结构：原 MODNet 的最后一个 36 维隐藏层 → 可学习 Dense 16 维投影 → 无仿射参数的 LayerNorm → `0.5*tanh` → 16→1 KAN 或 16→8→1 ELU MLP → 标量门控 → 加到原线性预测上。投影 592 参数、修正核心 145 参数、门控 1 参数，共新增 738 参数。两种模型的投影初始化、主干权重和训练批次随机种子配对一致；门控初始为零，初始预测与原 MODNet 完全相同。门控非零后所有支路参数参与计算，不用无效参数补齐容量。

物理分组核心仍各有 148 参数，拼接 4 个新特征后还增加第一层连接。无正则 KAN 与原稀疏 KAN 同时改变稀疏项及平滑项，因此消融只能说明这两项的合并影响，不能单独归因于某一项。

## 统一训练协议

- 目标均值和标准差只从当前内层训练集拟合；所有模型预测还原到 cm^-1 后比较 MAE。
- 仍使用同一份训练集拟合的输入 minmax 缩放；无新全局筛选、全局目标缩放或外层统计。
- 相同 96/72/36/36 主干，Adam，batch 32，学习率 {0.001, 0.0005}。
- 最多 400 轮；按内层验证 MAE 早停，patience 40、物理单位 min_delta 0.05。
- 对所有模型恢复内层验证 MAE 的精确最低点权重，而非最后一轮权重。
- 第一基础种子 20261027，各折再加折编号，所有模型配对使用。
- 原稀疏诊断模型仍使用 sparse=0.01、smooth=0.001。在标准化目标单位下，惩罚的目标尺度为 1，保持原相对目标形式。

这轮改变了目标缩放、早停与恢复权重规则，不能直接与旧快筛相减来宣称架构提升；只能与本轮同步训练的增强 MODNet 和 MLP 比较。验证集选择 epoch 属于调参，报告的内层成绩因此有选择偏差。

## 搜索预算与停止条件

第一阶段 6 模型 × 2 学习率 × 5 内层折 = 60 次训练。KAN 精度候选和 MLP 对照各两种结构，各 20 次训练；MODNet 基线 10 次；稀疏 KAN 消融 10 次。诊断模型不能参与 KAN 家族最优候选选择，避免额外搜索机会。

每种结构在完整五折平均分上选择学习率；分别选择最佳 KAN、最佳 MLP，并保留最佳 KAN 所对应的等参数 MLP。只有最佳 KAN 同时满足以下条件，才追加新种子验证：

- 相对增强 MODNet、最佳 MLP、对应等参数 MLP，平均 MAE 均至少降低 1%；
- 对以上每个比较，至少 4/5 折改善。

符合条件后冻结结构和学习率，使用基础种子 20271027，在同一五个内层划分上复核上述 3–4 个唯一配置，追加 15–20 次训练。禁止根据第二种子的结果重新选学习率。未达条件则止于 60 次，并保留所有负结果。第二种子检验初始化敏感性，不构成新的独立测试集。

## 交付与运行

入口：`scripts/start_mattervial_kan_refinement.ps1`，2 个 CPU worker；不修改原正式长任务的源码或进程。

- `protocol.json`：训练前冻结的输入和源码哈希、预算、候选与条件。
- `status.json`：当前状态和已完成训练数。
- `screening-summary.json`、`screening-report.md`：60 次初筛完整结果。
- `frozen-stage1-selection.json`：追加种子前冻结的候选和判定。
- 如进入追加阶段：`confirmed-summary.json`、`confirmed-report.md`。

启动前通过 5 项完整性测试，包括精确参数匹配、零残差初始预测、非零门控时支路梯度、序列化还原、训练集目标统计、完整五折择优、诊断候选排除、六个模型实际合成数据训练及最佳权重/预测/断点验证。合成数据结果不作为模型性能证据。
