**已完成 benchmark 中的 KAN 可解释性：证据、代表性中间量与边界（2026-11-06）**

可以找到有用的解释对象。最有证据支持的是具名描述符的响应函数、训练中心化后的预测贡献，以及删除该分量后的误差变化。现有结果支持 KAN 的内部函数便于检查，但尚未建立它比 MLP 更能识别物理机制或更容易提取简洁物理公式的经验优势。

本次没有重新训练。复核了早期物理坐标实验的 40 个 KAN，并从已完成的 phonons、steels 正式 benchmark 中各提取五个模型的内部量。后者固定采用每个外层折保存列表中的第一个 MM KAN 成员，共 10 个；没有根据外层成绩选择例子，也没有加载新的外层测试行或标签。它们是正式集成中可复现的示例子集，不能代表每折全部 50 个成员的内部统计。

![物理分量](../benchmarks/interpretability-review-20261106/physical-components.png)

图中细线对应全部 10 次训练，粗线为平均，阴影是运行间标准差。横轴只显示各训练集 5%—95% 区间的交集。平均半径和平均键长增大时，相应主效应总体下降；半径偏差的主效应总体上升。平均质量曲线在较大质量区变平并有轻微回升，不能仅凭左右端点下降就称其全局单调。

这些曲线可以转化为比单个样条系数更直观的“经验参数”。例如平均键长主效应在约 2.896 Å 附近的十次运行平均局部斜率为 −214.95 cm⁻¹/Å；平均共价半径在约 126.24 pm 附近为 −4.93 cm⁻¹/pm。这是指定模型分量的局部导数，包含交互项的完整预测导数还要加上交互项的导数；它们都不是材料的力常数。共同区间内的端点响应差分别约为 −222.45 和 −381.27 cm⁻¹。原始范围、每次运行的曲线和导数均保存在 `evidence.json`。

质量与成键描述符具有物理动机：声子频率来自质量加权力常数矩阵的本征值。但平均原子质量不等于模态有效质量，共价半径和键长也不是直接测得的力常数。当前响应只适合提出关于质量、尺寸与成键的经验假设。[Phonopy 动力学矩阵](https://phonopy.github.io/phonopy/formulation.html#dynamical-matrix)

**两变量中间量中，质量—电负性项比质量—键长项更稳定。** 独立物理乘积 KAN 的完整 `g(mean_mass) h(mean_electronegativity)` 项，训练平均绝对贡献为 31.731 cm⁻¹，删除后 MAE 平均增加 7.746 cm⁻¹，10/10 次变差；在各训练划分都覆盖的二维区域，曲面相关性中位数为 0.9859。质量—键长项相应为 15.148、+2.212、9/10 和 0.7429。

应比较完整乘积项，因为两个因子的幅度与符号可以互相补偿。该形式不意味着发现了质量与电负性的物理乘法定律；这四组输入配对原本就是人为预设的。混合 MODNet+物理乘积 KAN 的同一质量—电负性曲面相关性降为 0.2455，删除后的平均 MAE 变化约 −0.023 cm⁻¹。这一反例说明：独立小模型中稳定的分量，并不自动成为高精度混合模型中的稳定机制。

**单个样本也可以给出完整、精确的贡献账本。** 独立物理乘积模型 seed 0、inner fold 0 中，按 ID 字典序固定选择的验证样本 `mb-phonons-0012`，基准值为 556.465 cm⁻¹，20 项贡献合计 −7.732 cm⁻¹，预测为 548.733 cm⁻¹。其中平均键长项 +64.871、平均半径项 +55.870、半径偏差项 −135.341 cm⁻¹。完整各项都已保存，不能只显示正项或几项大项而省略抵消。40 个物理 KAN 的权重→分量复算最大误差为 2.85×10⁻¹⁴ cm⁻¹，分量→保存预测的最大误差为 4.55×10⁻¹³ cm⁻¹。

**正式 benchmark 的 KAN 也有可检查的中间量，但隐藏节点尚不能命名为物理量。** 当前实现每条边使用 8 个固定结点三次 B 样条，后续坐标逐维经过 `0.5*tanh`。第一层输入保留描述符名字；深层节点是多个响应的组合。

设最终样条层为 `b + Σ_j φ_j(z_j)`，目标标准差为 σ、均值为 μ，则可定义：

`c_j(x) = σ [φ_j(z_j(x)) − mean_train φ_j(z_j)]`

`y_ref = μ + σ [b + Σ_j mean_train φ_j(z_j)]`

`y_hat(x) = y_ref + Σ_j c_j(x)`

`c_j` 是有目标单位的精确输出通道贡献。中心仅使用该成员实际训练样本，不混入内层验证集；不同折的节点编号不可直接对应。phonons 折 0 的示例结构为 190→34→16→1。样本 `id1002` 的计算为 `564.044 − 242.873 = 321.171 cm⁻¹`，其主要通道包括 `c5=-175.758`、`c2=+167.223`、`c14=-134.839`。这解释了模型如何组合数值，但不能将 c5 命名为质量贡献。

![正式模型中间量](../benchmarks/interpretability-review-20261106/native-intermediates.png)

该成员的 7/16 个末层项承载 90% 的训练平均绝对贡献幅度。五个 phonons 示例的对应数目为 7/16、13/47、13/33、9/21、4/5。这个比例既不是解释方差，也不保证删掉其他通道后精度保留。10 个正式模型的输出贡献复算与原 TensorFlow 推理相差不超过 0.000536（各任务目标单位），差异来自浮点求和。

第一层的非线性边也确实可见。例如 phonons 折 0 的平均质量→h1[16] 边，在训练坐标上用最佳仿射函数近似，RMSE 为该边响应标准差的 30.3%；平均键长→h1[17] 为 12.4%。这些边包含可直接检查的弯曲形状。这个诊断没有替换边，也没有证明它们导致 KAN 优于 MLP。

steels 的五个示例也已保存全部三层权重、中间激活和末层贡献。按训练第一层边响应幅度选出的输入，折 0 包括 Co 原子分数、Miedema 相互作用焓描述符和 s 轨道未填充态数的平均偏差；其他折的候选包含 Al、Ti、Fe、Mo 原子分数。候选跨折变化明显，且这个选择指标尚未计算它们对最终输出的贡献。因此目前适合做成分通道案例，不宜据此宣称发现 Co 强化或某种冶金机制。

**KAN 的结构提供了方便，但“更稳定”“更简洁”尚未胜过 MLP。** KAN 把可学习单变量函数放在边上，因而能够直接导出输入→节点的函数形状；这是原论文的可解释性出发点。[KAN 原论文](https://arxiv.org/abs/2404.19756) 普通 MLP 第一层单条边是标量权重乘输入，但也能通过整体响应、梯度、归因等方式分析；末层加性贡献分解本身也不是 KAN 独有。

正式 phonons MM 模型的五折 ALE 曲线，平均质量、平均键长、平均半径的跨折相关性中位数，KAN 分别为 0.9979、0.9932、0.9964，MLP 分别为 0.9992、0.9997、0.9998。该结果支持“两个模型都学到了稳定响应”，不支持“KAN 在这些变量上更稳定”。ALE 是整模型的描述性局部响应累积，并非某条原生边、精确物理贡献或因果效应；图中的响应幅度也不能直接视为预测重要性。

![架构响应对照](../benchmarks/interpretability-review-20261106/benchmark-response-comparison.png)

简式提取的既有负结果同样应保留。固定方案把正式 KAN 的所有边统一替换为 1—3 阶多项式，以训练教师预测的交叉验证误差不超过教师预测标准差的 1% 为接受条件；500 个模型均未通过，全部保留原样条，系数压缩率为 0%。这不意味着每条边都不可简化，但不能把回退后的相同 MAE 称为无损符号化。8 描述符加性代理也未保持性能，KAN 代理的外层 MAE 约 202—203 cm⁻¹。小型物理乘积 KAN 可简化边比例只有 1.25%，平均仍需保留 19/20 个分量。

物理描述符之间亦有明显相关：平均半径与平均键长约 r=0.88，每原子体积与平均键长约 r=0.94。即使曲线很稳定，也存在贡献分配不唯一。单个样条系数依赖基函数、坐标缩放和偏置约定；混合分支的 gate 还与分支权重相互缩放。更值得报告的是完整函数、原始单位上的局部导数、中心化贡献、训练支持范围和删除分量后的变化。

**适合当前结果的研究表述是：**“KAN 提供了可直接审计的非线性边函数。直接物理输入的加性/乘积模型能形成稳定、精确的经验贡献分解；高精度 benchmark 模型也能进行内部通道审计，但其潜变量尚未获得唯一物理意义，且现有对照未显示更强的曲线稳定性或成功的整体符号压缩。”

若继续验证，优先围绕平均半径、半径偏差、键长和质量—电负性项开展工作：对相关变量做组级删减和重训，比较 KAN、MLP 与样条 GAM 在相同输入、预算、误差水平下的解释稳定性；对正式集成的全部成员开展选择性边简化，并仅用训练/内层证据决定替换。物理定律主张还需要独立材料子群或受控结构/同位素扰动验证。这里列的是后续建议，本次没有执行这些新训练或物理计算。低阶乘积与模块分析的研究背景可参见 [KAN 2.0](https://arxiv.org/abs/2408.10205)。
