# 冻结完整 KAN 的嵌套配对验证协议

2026-10-28。用户要求冻结完整 KAN＋近线性初始化，给等参数 MLP 相同调参预算，用新种子、新内层划分验证，稳定后再评估外层测试。

## 固定模型

增强输入 KAN 256→17→8→1，35,994 参数；配对 MLP 256→96→72→36→45→1，35,995 参数。物理输入 KAN 16→17→8→1，3,354 参数；配对 MLP 16→75→27→1，3,355 参数。

KAN 保留三次 B 样条边、固定网格、隐藏逐维 0.5*tanh、Greville 节点近线性初始化与原有小噪声。没有 MODNet 主干、残差、额外正则或剪枝。MLP 固定 ELU 激活和原有初始化。只调共同的学习率；结构、初始化不再搜索。

## 分层隔离与预算

仅使用官方 phonons 外层第1折的 1,012 个训练样本；253 个外层测试样本在通过稳定性门槛前不参与数据读取和训练。本轮重新生成五个内层确认折，种子 380281，与此前五折均不同。

每个确认折依次进行：

1. 保留约 20% 作确认集。剩余约 80% 内再固定划出 20% 作调参验证集（划分种子 380283＋折号）。确认集完全不进入该折调参。
2. 在调参训练集上重新筛选特征和拟合缩放。KAN/MLP 各试学习率 0.0005、0.001、0.002；各用两个新种子 480281、481281（加折号）。Adam、batch 32、最多 400 轮；仅调参验证 MAE 早停，patience 40，min_delta 0.05 cm⁻¹，恢复最低 MAE 权重。
3. 每个模型、输入组独立按两个种子的平均调参验证 MAE 选学习率；平分时选较小学习率。固定重训轮数为所选学习率两个最佳轮数的中位数，四舍五入。
4. 在整个确认训练部分重新筛选特征、拟合缩放，以两个新的确认种子 580281、581281（加折号）重训固定轮数。训练时不传确认集，不用确认集早停，不选确认集最佳 checkpoint。训练和保存模型后才预测、计分。

两组输入 × 两个模型 × 五折 × 三学习率 × 两调参种子 = **120 次调参训练**；加上两确认种子共 **40 次确认训练**，合计 **160 次**。每个模型家族本轮均为 60 次调参＋20 次确认，容量匹配；实际训练轮数和耗时可以不同。

所有 SISSO 都排除。增强特征为固定 16 个物理描述符＋训练部分 XGB gain 排序前 240 个其他特征；物理组取相同数据中的固定 16 列。固定零填充不拟合数据，特征筛选、输入 minmax 和目标标准化只拟合相应训练部分。新划分必须重新筛选，不能沿用旧划分筛出的特征。两个模型共享每个训练范围内完全相同的输入。

## 事先固定的稳定性标准

主要结论以增强输入组 KAN 对等参数 MLP 为准，必须同时满足：

- 两种子、五折的平均 MAE 相对改善至少 2%。
- 两个种子的五折均值分别都改善。
- 十次配对至少胜出七次，每个种子至少胜出三折。
- 每折对两个种子取平均后，至少五折中的四折改善。

物理输入组单独报告，不能用它通过来替代增强组未通过。门槛是事先声明的实际稳定性判据，不是统计显著性检验；两种子与交叉验证折之间并非独立数据集。任何训练缺失、失败或非有限分数都不得通过门槛。

## 条件外层评估

按当前默认范围，通过增强组门槛后先评估**官方外层第1折**。此阶段各模型和输入组仍只用内层调参结果选学习率：每个学习率汇总五个调参子划分、两个种子；轮数取选中学习率十次最佳轮数的四舍五入中位数。该规则在确认前冻结，不根据确认结果手工改动。

对全部 1,012 个外层训练样本重新筛特征、拟合缩放，以新种子 680281、681281 各训练一次；KAN/MLP、两组输入合计八次。外层标签不传入训练、早停或模型选择。报告每个种子的成绩及固定两模型平均预测的集成成绩，不择优种子。两个模型、两种输入一同报告，不能只公开有利结果。

未达标则停止，不运行外层。第1折成绩不能称为完整五折 benchmark。若用户指定完整五折，应单独固定每折训练范围和预算，不得把第1折结果用于后续折调参。

## 限制与可复查记录

新划分和新种子仍来自过去探索过的同一批 1,012 个样本，因此检验的是重新划分后的稳定性，不是独立新数据集的验证。此次双方调参预算相同，也不消除过去模型设计时的不对称探索。预训练嵌入的来源限制仍然存在。

运行目录保存模型与训练源码哈希、完整划分、输入与目标变换拟合 ID、逐次训练预测和权重、学习率选择文件、稳定性门槛判定和（若运行）外层成绩。旧实验和运行中的正式复现脚本保持不变。预处理最多两个 worker，模型训练最多四个 worker，每个 worker 限单线程；原有正式复现任务继续运行。
