# 声子峰差可由五个 KAN 节点和两个物理量还原多少

在 Matbench Phonons 已有的 58 对同结构原型晶体上，**给两个网络同样的五个节点，再要求每个节点的贡献都能用最短原子间距和最轻元素质量复算，增强 KAN 还原了 77.9% 的完整预测峰差方差，MLP 为 31.6%**。对 DFPT 参考峰差，这套物理解释的平均绝对误差分别是 53.3 和 108.5 cm⁻¹，五折均为 KAN 更低。只用 Matminer 描述符重复，结果为 83.2% 和 43.9%，参考峰差误差分别是 52.1 和 101.8 cm⁻¹。

这里的五个节点是**每个冻结成员**五个。每种架构每折 50 个成员。把各节点的近似函数加起来，全折的解释可压成两条曲线。给定真实晶体 A 和 B 的两个物理量，可以直接计算峰差，无需运行神经网络。[两条曲线的结点、系数和复算公式](../benchmarks/phonons-equal-budget-20261113/two-physical-curves.json)

![真实晶体对上两种解释的保真度，以及 LiH 换为 LiI 时各物理量对应的峰位下降量](../benchmarks/phonons-equal-budget-20261113/physical-effectiveness.png)

## LiH 和 LiI 的具体变化

LiH（`mb-phonons-0353`）和 LiI（`mb-phonons-0285`）都是岩盐型，保留了锂，另一种元素由 H 换为 I。沿用前次定义的全部 58 对真实对照，这一对的 DFPT 参考峰差绝对值最大。选择依据只用了参考峰差。两件晶体都在外层第 3 折测试集。

最近邻距离从 **2.0001 Å 增至 3.0129 Å**。最轻元素从 H（1.00794 u）变为 Li（6.941 u）。因此两条曲线的输入都改变了。DFPT 参考峰位从 1,045.6 降至 285.6 cm⁻¹，下降 **760.0 cm⁻¹**。简谐声子的频率取决于质量加权的力常数矩阵。距离提供局域成键的信息，轻元素质量提供高频振动的质量尺度。一次元素替换也改变电子结构，表中的分量是从模型读出的经验贡献，元素替换本身无法分别测定力常数与有效质量的因果贡献。[数据定义](https://hackingmaterials.lbl.gov/matminer/dataset_summary.html#matbench-phonons) · [声子动力学矩阵](https://phonopy.github.io/phonopy/formulation.html#dynamical-matrix)

| LiH → LiI，增强模型，单位 cm⁻¹ | KAN | MLP |
| --- | ---: | ---: |
| 完整模型给出的峰位变化 | −796.3 | −673.0 |
| 五个节点的原始贡献之和 | −652.1 | −302.6 |
| 由最短距离复算的贡献 | −351.15 | −183.70 |
| 由最轻元素质量因子复算的贡献 | −292.18 | −150.45 |
| **两项物理解释之和** | **−643.33** | **−334.15** |
| 还原 DFPT 下降幅度的比例 | **84.6%** | **44.0%** |

这个百分比是单对材料的下降幅度比。前面 58 对的百分比是跨材料对的 R²，两个指标的分母不同。上一轮展示的 BN → BAs 在这个更严格的检验下，最轻元素硼保持不变，两项只给出 −203.3 和 −99.5 cm⁻¹，DFPT 为 −522.0 cm⁻¹。[逐材料对、逐物理量的有符号结果](../benchmarks/phonons-equal-budget-20261113/summary.json)

## 怎样保证五个节点确实参与了原预测

1. 每个外层折只在其训练晶体间配对。要求二元 1∶1 组成、相同空间群及配位验证过的结构原型、两种元素中只换一种。五折分别有 140、204、203、138、180 对训练对照。留出晶体按同一规则得到 21、5、4、21、7 对，共 58 对、66 件晶体。每个成员进一步只用其自身拟合过的训练晶体对选择节点、标定物理曲线。
2. 在每一个隐藏层，把两个真实材料之间的完整峰差逐层回算到节点，保留原有有符号贡献和物理单位。KAN 使用各样条边的两端响应差，MLP 使用稠密权重与激活函数的两端差商。每层全部节点贡献之和等于原整网峰差。对两种架构都遍历所有隐藏层，每层按同一贪心规则添加能最大降低训练重建误差的节点，再由训练误差决定使用哪一层。每组节点来自同一层，避免同一路径在不同层重复计数。筛选不重新拟合节点权重。[全层回算与节点选择](../scripts/audit_phonons_explanation_budget.py) · [KAN 的可学习边函数定义](https://arxiv.org/abs/2404.19756)
3. 对选中节点 \(j\)，只用它自身在训练对上的原始贡献拟合两条一维曲线。令 \(d\) 为最短间距，\(u=1/\sqrt{M_{\min}}\)。该节点在 A → B 上的近似贡献是 \(f_j(d_B)-f_j(d_A)+g_j(u_B)-g_j(u_A)\)。每条曲线最多用三个训练四分位内结点，使用相同的岭惩罚。拟合对象为该节点的 cm⁻¹ 贡献，DFPT 测试标签只参与最后的评分。
4. 外层测试时，每个成员把五项相加，然后取 50 个成员的均值。这仍然可以写成两条加和曲线，\(\Delta\hat\nu=F_d(d_B)-F_d(d_A)+F_u(u_B)-F_u(u_A)\)。系数折叠后，用测试晶体的结构和组成独立复算了每个物理分量，对各成员逐项求和的结果核对到 \(10^{-7}\) cm⁻¹。曲线是对节点原始贡献的有监督近似，五个节点本身来自原网络。[物理曲线标定](../scripts/distill_phonon_nodes_to_physics.py) · [独立复算及汇总](../scripts/score_phonons_explanation_budget.py)

## 58 对真实元素替换上的结果

“保留原生五项”允许读取完整网络激活。“五项用两个物理量复算”在留出对上只读取真实距离和质量。R² 衡量对各自完整模型峰差的还原程度，最后两列衡量这些简化解释对 DFPT 峰差的误差。

| 输入与解释规则 | KAN 峰差 R² | MLP 峰差 R² | KAN 对 DFPT 的 MAE | MLP 对 DFPT 的 MAE |
| --- | ---: | ---: | ---: | ---: |
| Matminer，保留原生五项 | 97.6% | 56.1% | 42.5 | 99.6 |
| Matminer，五项用两个物理量复算 | **83.2%** | **43.9%** | **52.1** | **101.8** |
| Matminer + MatterVial，保留原生五项 | 93.9% | 46.6% | 40.6 | 105.8 |
| Matminer + MatterVial，五项用两个物理量复算 | **77.9%** | **31.6%** | **53.3** | **108.5** |

两套输入下，两物理量解释对 DFPT 的 MAE 各下降 **48.8% 和 50.8%**，都是 58 对中 46 对的绝对误差更小。每件晶体最多使用一次，按原记录顺序保留 26 对，增强 KAN 和 MLP 对整网峰差的 R² 仍为 **76.9% 和 26.7%**，对 DFPT 的 MAE 为 **54.4 和 113.5 cm⁻¹**。材料对有重复端点，各折训练集也重叠，这些是同一数据集上的配对结果。

进一步要求**每个节点只能选一个物理量**，由训练误差在距离和质量因子中二选一。在增强输入上 KAN 和 MLP 的留出峰差 R² 分别为 61.8% 和 −0.3%，在 Matminer 上为 66.8% 和 6.3%。

## 优势来自哪里

增强 KAN 有 232/250 个成员从靠近输出的隐藏层选出五个节点，剩余 18 个从前一层选出。MLP 在四个隐藏层均选到过节点。KAN 输出边的原生贡献是单变量样条的响应差，少数项可以承载较大份额的最终变化。MLP 的预测在这个预算下分布在更多节点上。按同一误差尺度检查五个节点**各自**被两物理量拟合的程度，增强 KAN 的 \(1-\sum(\hat c-c)^2/\sum c^2\) 为 73.8%，MLP 为 81.5%。MLP 的单项可以拟合得很好。决定最后差距的是五项原本合起来承担了多少峰差。[节点数从 1 到 10 的误差曲线](../benchmarks/phonons-equal-budget-20261113/native-terms.png)

两个对照给出了这个结论的适用条件。

- 把预算改成各自隐藏层宽度的四分之一，两者可以保留不同数量的节点。增强输入上的原生贡献 R² 为 96.0% 和 95.5%，Matminer 输入为 97.1% 和 97.9%。相同绝对节点数对应 KAN 较窄隐藏层的更大比例。
- 允许两条物理曲线直接拟合完整模型峰差，跳过对五个节点的逐项对应，增强模型两种解释对 DFPT 的 MAE 为 49.1 和 48.7 cm⁻¹。若改为一次选同样五类原始 Matminer 描述符，Matminer 模型的峰差 R² 为 38.3% 和 57.3%。这些结果把优势限定到**以少量原生项为依据的物理解释**。

## 固定原始输入和训练配置后再比

两套模型原来分别完成选模。为控制输入和搜索差异，另取原实验初代双方完全相同的 20 个候选配置。每折每配置各 5 个成员，两套输入共 1,000 对已训练模型。逐对验证了输入列及顺序、输入缩放后的值、训练与验证 ID 和随机种子，取两边内层验证误差的名次和选择共同配置。不同架构按原规则匹配参数量，实际参数差最大为 6.72%，目标缩放仍沿用各自原训练流程。对共同验证第一名及共同前十名预留相同的解释预算，重复独立的测试峰差重建。[同配置模型核验及留出预测](../scripts/audit_phonons_explanation_budget.py) · [同配置的物理解释复算](../scripts/check_phonons_matched_explanations.py)

| 对原始输入和训练配置的控制 | KAN 两个物理量还原峰差的 R² | MLP 相同解释的 R² | KAN 对 DFPT 的 MAE | MLP 对 DFPT 的 MAE |
| --- | ---: | ---: | ---: | ---: |
| Matminer，共同验证第一名 | 82.6% | 24.0% | 50.3 | 122.1 |
| Matminer，共同前十名 | 83.3% | 59.8% | 61.3 | 84.1 |
| 增强输入，共同验证第一名 | 79.1% | 65.7% | 54.8 | 65.9 |
| 增强输入，共同前十名 | 82.2% | 63.6% | 60.1 | 71.0 |

共同第一名的每一对成员都使用 5 个节点。增强输入共同前十的 250 对成员中，有 15 对的 KAN 最宽隐藏层只有 4 个节点，这 15 对同时限制 MLP 为 4 个节点。其余配对均为 5 对 5。控制输入后，增强模型的解释差距缩小，汇总结果仍然偏向 KAN。

## 完整模型的预测效果

| 1,265 个真实晶体，官方五折 | KAN MAE（cm⁻¹） | MLP MAE（cm⁻¹） | KAN 误差较低的折数 |
| --- | ---: | ---: | ---: |
| Matminer | **29.45** | 33.93 | **5/5** |
| Matminer + MatterVial | **28.23** | 28.76 | 2/5 |

这些是分别完成选模的正式集成。Matminer 输入下，KAN 的平均绝对误差降低 13.2%，1,265 件中有 750 件的绝对误差更小。增强输入下，均值改善为 1.8%。在 58 个同原型对照上，两个完整模型的峰差 MAE 分别为 37.8 和 35.7 cm⁻¹（Matminer），33.9 和 37.1 cm⁻¹（增强）。个体峰位与两种材料间的峰差是不同的预测目标。[原正式五折对照](../benchmarks/native-fourway-scaled-kan-20261029/report.md) · [上一轮全体晶体的两物理量读出](phonons_frequency_explained_20261113.md)

同配置模型的**完整预测**也反映了训练配置的影响。只用共同验证第一名时，两种输入下的个体峰位 MAE 分别为 32.18 对 36.27、33.69 对 31.34 cm⁻¹（KAN 对 MLP）。平均共同前十个配置时，两组变为 45.53 对 34.10、60.86 对 28.99 cm⁻¹。较差的训练配置拉高了 KAN 的预测误差。这项对照支持用少量节点提取物理解释的优势，也说明完整预测应在各自充分选模后比较。
