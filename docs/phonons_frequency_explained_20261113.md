# 两个晶体物理量能解释多少声子峰位变化

后续把每个成员限制为五个真实节点，并逐项用距离和质量复算，在同一批元素替换上比较了 KAN 与 MLP 的解释误差。[固定五个节点时哪种物理解释更有效](phonons_five_node_physical_effectiveness_20261113.md)

Matbench Phonons 收录了 1,265 个晶体。这里解释的是声子态密度最高频一侧的峰位，单位为 cm⁻¹，参考值来自密度泛函微扰理论计算（DFPT）。沿用已训练的 MM + MatterVial KAN 和 MODNet/MLP。每种架构、每个官方外层折有 50 个成员，共复核 500 个模型。所有晶体、组成、结构坐标和参考峰位均来自现有存档。每件材料只在所属的留出折计分。[Matbench 数据定义](https://hackingmaterials.lbl.gov/matminer/dataset_summary.html#matbench-phonons) · [Petretto 等的声子计算](https://pmc.ncbi.nlm.nih.gov/articles/PMC5928854/)

## 哪两个量概括了整个网络

**最短原子间距** \(d_{\min}\) 是周期性晶体中最近两个原子之间的距离，计算时包括相邻晶胞。**最轻元素的质量因子** \(1/\sqrt{M_{\min}}\) 中，\(M_{\min}\) 是组成中最轻元素的标准原子质量。短距离常提示较强的局域回复力，轻原子可以参与高频振动。简谐晶体的频率由质量加权力常数矩阵的本征值决定。距离和元素质量可以直接从结构记录得到，具体振动模式的有效质量和力常数还取决于本征矢和局域成键。[声子动力学矩阵](https://phonopy.github.io/phonopy/formulation.html#dynamical-matrix)

每折用其余 1,012 件真实晶体上的冻结模型预测拟合下式，再在该折 253 件真实晶体上验证。候选集包含既有分析的 12 项平均质量、几何、电负性和配位等指标，并加入上述两个针对高频振动的量，共 14 项。两种架构用相同的候选、变量数和函数复杂度，每种架构分别标定系数。每个变量最多使用三个内结点，位置取训练资料中实际出现的四分位数。每步选出最能降低训练预测误差的变量。两架构共同选或各自独立选，**五折都先选最短原子间距，再选最轻元素质量因子**。[每折候选选择、系数与函数取值范围](../benchmarks/phonons-all-input-paths-20261113/readout.json)

\[
\widehat{\nu}_{\mathrm{peak}}=b+f(d_{\min})+g(1/\sqrt{M_{\min}}).
\]

| 五折留出晶体上的结果 | KAN | MLP |
| --- | ---: | ---: |
| 仅最短间距对整网预测的 R² | 82.13% | 82.45% |
| 两个量对整网预测的 R² | **92.86%** | **92.86%** |
| 两个量对整网预测的 R²，各折范围 | 92.11%–93.65% | 92.21%–93.51% |
| 排除全部 62 个含氢晶体，两量对整网预测的 R² | 91.31% | 91.18% |
| 两个量对 DFPT 参考值的 R² | 92.41% | 92.46% |
| 两变量公式对 DFPT 的平均绝对误差 | 82.89 cm⁻¹ | 82.96 cm⁻¹ |
| 原完整网络对 DFPT 的平均绝对误差 | 28.23 cm⁻¹ | 28.76 cm⁻¹ |

92.86% 衡量跨晶体的峰位方差。两个量能分清大部分高频与低频材料，个别晶体仍有明显的峰位误差。只用原来的 12 个候选，最佳三变量组合在五折都为平均共价半径、位点平均键长的标准差、平均电负性，对两架构的留出预测 R² 分别为 67.20% 和 67.40%。扩大到 14 项后增加第三个量，KAN 和 MLP 的 R² 分别为 92.89% 和 92.85%，与两变量结果相近。[留出预测和各材料物理量](../benchmarks/phonons-all-input-paths-20261113/readout.npz)

## 在两块真实晶体上核对峰位差

立方 BN（`mb-phonons-0200`）与 BAs（`mb-phonons-0002`）同属闪锌矿型、空间群 216，硼周围各有四个最近邻。氮和砷同属第 15 族。二者的最轻元素均为硼，质量 10.811 u。这个例子从满足同原型、同族替换、最轻元素质量相同的 13 对真实材料中，按 **DFPT 峰差绝对值最大** 选出。两件材料同在外层第 0 折，选择示例时没有用 KAN 与 MLP 之间的表现差。[配对记录和选择条件](../benchmarks/phonons-all-input-paths-20261113/catalogue.json)

| 量 | 立方 BN | BAs | BAs 减 BN |
| --- | ---: | ---: | ---: |
| 最短原子间距 | 1.570 Å | 2.087 Å | +0.517 Å |
| DFPT 参考峰位 | 1,223.6 | 701.6 | **−522.0 cm⁻¹** |
| KAN 完整预测 | 1,205.7 | 641.4 | **−564.3 cm⁻¹** |
| MLP 完整预测 | 1,227.7 | 722.0 | **−505.8 cm⁻¹** |
| 用两种物理量近似 KAN | 1,198.8 | 599.8 | −599.1 cm⁻¹ |
| 用两种物理量近似 MLP | 1,199.1 | 596.7 | −602.5 cm⁻¹ |

质量因子固定，透明公式把这对晶体的峰差全部写进了距离项，和完整模型的峰差分别相差 34.7、96.7 cm⁻¹。**在 13 对同类对照中，间距增大时，DFPT 有 12 对峰位下降，KAN 与 MLP 均预测 13 对下降。** 例外是岩盐型 RbCl 与 CsCl，参考峰位上升约 9 cm⁻¹。这些晶体同时改变了成键和元素质量。以 BN 与 BAs 为例，按两种原子的质量算出的二体约化质量从 6.10 增至 9.45 u。现有对照能说明距离对峰位有指示意义，单独拉长同一根键的因果效应仍无法从这组数据识别。

## KAN 的输入贡献更少相互抵消

对同一对真实材料，调用每个冻结成员的所有隐藏层，使用两端已有激活值回算每个原始输入对预测差的有符号贡献 \(c_i\)，单位为 cm⁻¹。KAN 使用原生样条边函数的两端差，MLP 使用稠密层权重和激活函数的两端差商。偏置在材料差值中抵消。逐个输入在 50 个成员间取平均后，\(\sum_i c_i\) 还原该架构的完整集成峰差。所有配对的单成员加和误差小于 \(8\times10^{-13}\) cm⁻¹，集成峰差与正式存档的最大偏差为 0.000083 cm⁻¹。这个分配依赖原始描述符坐标和差商约定。[全层回算脚本](../scripts/trace_phonons_observed_pairs.py)

| BN → BAs 的输入贡献（cm⁻¹） | KAN | MLP |
| --- | ---: | ---: |
| 所有使峰位下降的输入贡献之和 | −686.7 | −989.1 |
| 所有使峰位上升的输入贡献之和 | +122.4 | +483.4 |
| 净峰差 | **−564.3** | **−505.8** |
| 明确依赖距离的几何描述符贡献 | −110.5 | −135.6 |
| 预训练材料嵌入的贡献 | −330.9 | −325.4 |

表中最后两行按描述符类别分组，与正负分类有重叠。几何描述符包含每原子体积、键长统计、径向分布、旋转不变的距离指纹以及 Voronoi 距离、面积和体积。相同理想结构原型内，这些量反映晶格长度尺度的变化。在 BN → BAs 上，这一组可直接认出的几何输入占净峰差 19.6% 和 26.8%。嵌入可能携带距离信息，现有分解无法把其中多少单独归给距离。这个逐项结果与透明公式的距离项回答的是两个不同问题。

把同样的检验扩展到 **66 件晶体组成的 58 对真实替换**。筛选只用结构和组成，要求同一外层测试折、相同的二元 1∶1 原型、共享一种元素。所选原型为岩盐、闪锌矿和 CsCl 型，逐个核对空间群、异种最近邻配位数、晶胞体积和两原子原胞。五折的对数为 21、5、4、21、7。设 \(C=|\sum_i c_i|/\sum_i|c_i|\)，越接近 1 表示正负抵消越少。

| 对照范围 | 对数 | KAN 的 C 中位数 | MLP 的 C 中位数 | KAN 抵消较少 |
| --- | ---: | ---: | ---: | ---: |
| 全部同原型替换，逐个原始输入 | 58 | **0.530** | **0.263** | **58/58** |
| 每件材料最多使用一次，按存档顺序取对 | 26 | 0.612 | 0.351 | 26/26 |
| 参考峰差超过 60 cm⁻¹，且两个整网峰差的误差都在参考峰差一半内 | 33 | 0.626 | 0.361 | 33/33 |
| 先在描述符家族内合并，再计算 C | 58 | 0.923 | 0.818 | 44/58 |

原始选模允许 KAN 和 MLP 使用不同数量的输入。另取输入列及顺序完全相同的 65 对成员复查，覆盖第 0、2、3 折。逐成员、逐材料对的 855 次比较中，KAN 有 725 次抵消较少，C 中位数为 0.352 和 0.211。成员共享训练数据，部分材料对也共用晶体。以上计数都是同一数据集内的描述性结果。较少抵消意味着解释一次峰位下降时，只需扣回较小的反向贡献。BN → BAs 上，MLP 的净峰差更接近 DFPT，峰位精度可单独核对。[逐材料对的有符号贡献、匹配成员和复核结果](../benchmarks/phonons-all-input-paths-20261113/summary.json)

## 同样的节点数能读出多少整网预测

允许两种架构从**所有隐藏层**选节点。对每个冻结成员的两个物理量分别做线性回归，选择节点和标定系数只使用该成员自己的训练晶体及其物理量。每个量各取 1 个或至多 4 个节点。对真实留出晶体，把节点读出的两个物理量代回前面冻结的两变量公式，最后汇总 50 个成员。表中指标均在五折留出晶体上计算。[相同节点预算的计算脚本](../scripts/probe_phonons_two_quantities.py)

| 留出 R² | KAN | MLP |
| --- | ---: | ---: |
| 每量 1 节点，读出最短原子间距 | 88.16% | 86.92% |
| 每量 1 节点，读出最轻元素质量因子 | 69.95% | 71.53% |
| 每量 1 节点，经物理公式还原整网输出 | 88.54% | **93.99%** |
| 每量 4 节点，经物理公式还原整网输出 | 94.49% | **96.48%** |

节点中还可能保留与峰位有关的其他信息，所以用节点估计两个物理量后，重建模型输出有时比用精确物理量更准。物理量本身的读出精度要看表中前两行。在这套检验里，KAN 的单节点对几何距离略易读，MLP 用相同节点预算还原整个预测更好。KAN 跨五折方向一致的优势出现在真实元素替换的**输入贡献抵消程度**上。

## 哪些比较更难

两变量公式解释 58 对同原型替换的整网**峰差方差**，KAN 为 77.4%，MLP 为 75.4%。同化学式的 24 对不同结构记录上，相应结果降到 47.6% 和 26.6%，峰差近似误差平均为 7.8 和 8.3 cm⁻¹。其间有一对 SiC 的 DFPT 峰差为 +87.0 cm⁻¹，两个整网都给出不到 1 cm⁻¹ 的下降。局部堆垛、力常数和振动模式对特定晶型的影响，仅凭最短距离和最轻元素难以解析。只用回算时明确标为距离几何的**原生输入组**，在 58 对同原型替换中，使近似误差低于整网峰差一半的两种架构都只有 1 对。

复算顺序为准备真实配对和全局读出、全层回算、等节点预算读出、统计汇总。另一份原数据发布存档逐件复核了 1,265 个官方 ID 下的化学组成、参考峰位、每原子体积和最短间距。两份结构计算的最短间距最大相差 \(3.6\times10^{-15}\) Å。可按官方 ID 从明细追溯每个示例。[真实对照与训练折拟合](../scripts/prepare_phonons_physical_pairs.py) · [汇总及原始结构交叉核对](../scripts/report_phonons_observed_pairs.py) · [钢任务的相同分析](steel_strength_explained_20261113.md)
