# 纯 Matminer 声子预测中，KAN 用多少个描述符能达到完整 MODNet 的误差？

在 Matbench Phonons 的 1,265 个晶体上，每折固定用 **64 个描述符**重新训练的 KAN 得到 **33.36 cm⁻¹** 的五折平均绝对误差，完整 MODNet 为 **33.93 cm⁻¹**。运行完整 MODNet 集成平均需 491.4 列。按相同的整套预测器口径，KAN 平均少用 **427.4 列（87.0%）**，MAE 低 **0.57 cm⁻¹（1.7%）**。64 是本次测试的 12 个档位中第一个达到该水平的列数，49–63 列仍待测量。

![纯 Matminer 声子预测中，不同输入数的 KAN 五折平均绝对误差、完整 MODNet 基线及其 5% 容许线](../benchmarks/phonons-mm-input-budget-20261114/feature-count-vs-mae.png)

## 对“差不多”的三种要求

事先采用的均值门槛为完整 MODNet 的五折平均 MAE × 1.05，即 **35.62 cm⁻¹**。下表中的逐折要求使用各折自己的 MODNet MAE 作参照。

| 对 KAN 预测误差的要求 | 首个达标的已测列数 | 相对完整 MODNet 平均少用 | KAN 五折 MAE（cm⁻¹） |
| --- | ---: | ---: | ---: |
| 五折平均最多高 5%，或更严格地要求平均误差不升高 | 64 | 87.0% | 33.36 |
| 每一个外折的 MAE 都最多高 5% | 80 | 83.7% | 32.05 |
| 每一个外折的 MAE 都不升高 | 96 | 80.5% | 32.19 |

64 列时有四折的 MAE 低于 MODNet。例外是第 0 折，36.64 对 32.69 cm⁻¹，高 12.1%。增加到 80 列，该折变为 33.02 cm⁻¹，高 1.0%。材料划分和模型随机性都会影响折间差异，5% 是实用误差容许值。这里报告的是观察到的成绩。

## 只用训练数据挑选输入数

另按每折自己的内层验证误差选列数。对每个内层验证集，把训练时留出它的 10 个原 MODNet 成员的预测取平均，计算 MAE，再对五个内层划分等权求均值。固定输入的 KAN 在同样的五个内层划分各有一个独立训练成员。依次检查 12 个档位，取首个内层平均 MAE 不超过该折 MODNet 内层基准 1.05 倍的档位。选定后，用这五个 KAN 对外层测试晶体的平均预测计分。

| 外折 | 完整 MODNet 列数 | MODNet MAE | 固定 64 列 KAN MAE | 固定 80 列 KAN MAE | 内层选出列数 | 内层选定 KAN 的外层 MAE |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 0 | 540 | 32.69 | 36.64 | 33.02 | 64 | 36.64 |
| 1 | 590 | 34.85 | 33.69 | 34.30 | 64 | 33.69 |
| 2 | 616 | 35.83 | 35.59 | 34.10 | 64 | 35.59 |
| 3 | 391 | 32.10 | 29.95 | 29.85 | 64 | 29.95 |
| 4 | 320 | 34.17 | 30.92 | 28.98 | 128 | 31.27 |
| **五折平均** | **491.4** | **33.93** | **33.36** | **32.05** | **76.8** | **33.43** |

这种训练集选法平均节省 **84.4%** 的列，外层 MAE 比完整 MODNet 低 **1.5%**。内层选模和特征排名沿用该外折的训练数据，排名是原实验在整个外层训练集上确定的，内层验证 MAE 用于选择。最终证据来自五份互不重叠的外层留出预测。[逐样本预测](../benchmarks/phonons-mm-input-budget-20261114/oof-predictions.csv) · [各档位、各折和选模结果](../benchmarks/phonons-mm-input-budget-20261114/summary.json)

## 单个成员和整个集成各需要多少列

两种架构在每个外折共享 Matminer 描述符和排序，分别搜索特征前缀长度、网络配置与训练超参数。第 0 折正式 KAN 的 50 个成员中，35 个取前 190 列、5 个取前 217 列、10 个取前 240 列。MODNet 有 40 个取前 190 列、10 个取前 540 列。每个前缀包含所有更短的前缀，因此两个完整集成分别需要 240 和 540 个不同的输入。换一个外折会重新选特征，列名和集合大小都可能变化。[第 0 折 KAN 选择记录](../benchmarks/native-fourway-scaled-kan-20261029/mm_kan/fold-0/frozen-selection.json) · [第 0 折 MODNet 选择记录](../benchmarks/native-fourway-scaled-kan-20261029/mm_modnet/fold-0/frozen-selection.json)

第 0 折 KAN 保存清单中的第一个成员确实为 **190 → 34 → 16 → 1**，输出声子态密度最高频端的峰位。重新加载权重后，三层的样条系数数组形状为 `(190, 34, 8)`、`(34, 16, 8)`、`(16, 1, 8)`，各有一个相应的偏置向量。7,020 条边各有 8 个系数，加上 51 个偏置，合计 **56,211 个可训练参数**。[正式模型报告](https://github.com/whpoly/kan_cgcnn/blob/8e29781e338cf6967c9862b42d0b9b9ed62c6caa/docs/kan_interpretability_review_20261106.md) · [参数计数公式](../scripts/native_fourway_models.py)

五折完整 MODNet 集成的列数为 540、590、616、391、320，完整 KAN 为 240、286、220、280、250。若关心单个网络的宽度，250 个正式 MODNet 成员平均各读 **317.6 列**，相对这个分母，64 列减少 **79.8%**。固定列数实验中，同折五个 KAN 成员读取完全相同的列。这里的百分比衡量模型读取的描述符列数。描述符从结构生成时可以共享计算，计算时间需要单独测量。

## 输入缩减后的参数量和网络结构

固定 64 列的档位在五个外折各从头训练了五个成员，共 25 个新模型。原 KAN 只提供各折的隐藏层宽度、种子和训练配置。每个新成员重新初始化并优化三层样条的全部权重。完整 MODNet 和原 KAN 的参数量、预测及 MAE 均取自各自已训练的模型。

| 模型 | 每折成员数 | 平均每个成员的可训练参数 | 平均每折整个集成的可训练参数 | 五折 MAE（cm⁻¹） |
| --- | ---: | ---: | ---: | ---: |
| 完整 Dense MODNet | 50 | 120,678.48 | 6,033,924 | 33.93 |
| 原完整 KAN | 50 | 101,795.44 | 5,089,772 | 29.45 |
| 原 KAN，保留各折验证第一名的五个成员 | 5 | 113,319 | 566,595 | 30.00 |
| 固定 64 列 KAN | 5 | **40,583** | **202,915** | **33.36** |
| 固定 80 列 KAN | 5 | 47,239 | 236,195 | 32.05 |
| 固定 96 列 KAN | 5 | 53,895 | 269,475 | 32.19 |
| 各折按内层验证选列数的 KAN | 5 | 41,709.4 | 208,547 | 33.43 |

从同样五成员的原 KAN 对照到 64 列 KAN，隐藏层宽度和成员数都相同，平均每个成员少 **72,736 个参数（64.19%）**，每折集成少 **363,680 个参数**。对应的 MAE 从 30.00 上升至 33.36 cm⁻¹。若以完整 MODNet 为基准，64 列 KAN 平均每个成员少 66.37% 的参数，整套集成少 **5,831,009 个（96.64%）**。整套的差异同时包含网络结构、输入维度和成员数从 50 减到 5 的影响。80 列相对同配置原 KAN 的单成员参数减少 58.31%，相对完整 MODNet 的集成总量减少 96.09%。

下表的 Dense 是各折完整 MODNet 中**按平均内层验证 MAE 排第一**的实际配置。完整参照还包括该折其余九套入选配置。KAN 两列是同一折、同一套隐藏层宽度在缩减输入前后的结构，括号中为每个成员的可训练参数。

| 外折 | 正式 MODNet 的代表性 Dense 结构 | 原五成员 KAN 结构 | 重新训练的 64 列 KAN 结构 |
| ---: | --- | --- | --- |
| 0 | 190 → 224 → 168 → 84 → 63 → 1（100,199） | 190 → 34 → 16 → 1（56,211） | 64 → 34 → 16 → 1（21,939） |
| 1 | 270 → 192 → 192 → 96 → 24 → 1（109,969） | 250 → 100 → 47 → 1（238,124） | 64 → 100 → 47 → 1（89,324） |
| 2 | 406 → 320 → 240 → 180 → 135 → 1（275,231） | 220 → 70 → 33 → 1（142,048） | 64 → 70 → 33 → 1（54,688） |
| 3 | 212 → 192 → 144 → 36 → 18 → 1（74,593） | 280 → 45 → 21 → 1（108,595） | 64 → 45 → 21 → 1（30,835） |

第 0 折每减少一个输入，会少掉它到 34 个第一隐藏层节点的 34 条边，每条边有 8 个系数。从 190 列降到 64 列，恰好减少 **(190 − 64) × 34 × 8 = 34,272** 个参数，即该成员的 **60.97%**。64 列模型的三层分别有 17,442、4,368 和 129 个可训练参数，包含各自的偏置。输出转换为 cm⁻¹ 的缩放层没有可训练参数。

代码中还有一套用于给原 KAN 匹配参数量的 Dense 宽度。第 0 折该 KAN 配置的参考结构为 **190 → 160 → 120 → 30 → 22 → 1（54,215）**。若仅在这个参考结构中将输入改成 64，公式给出 **34,055** 个参数。正式 MODNet 的验证第一名是表中的 100,199 参数结构，33.93 cm⁻¹ 来自完整 MODNet 集成。本次固定输入实验只重新训练了 KAN。

逐一检查了 250 个正式 MODNet 成员、250 个正式 KAN 成员与 300 个新 KAN 成员的模型文件哈希、网络定义和各层权重数组，并对所列代表结构重新加载 Keras 网络核对可训练参数。每折集成参数等于该折所有独立成员的参数之和，表中再对五折等权平均。[全部入选结构、逐折参数和减少比例](../benchmarks/phonons-mm-input-budget-20261114/parameter-counts.json) · [Dense 与样条计数公式](../scripts/native_fourway_models.py)

## 训练与核验

- 沿用原纯 Matminer 五折。每折 1,012 个训练晶体、253 个测试晶体，只预测单晶体的绝对峰位。每折先按原 KAN 搜索中五个内层验证 MAE 的均值挑出第一名，保留其隐藏层、种子、训练及验证划分、输入与目标缩放、优化器和停训规则。每档从头训练五个纯三次 B 样条 KAN，12 档 × 5 外折 × 5 成员共 300 次。每次只向模型提供相应训练排名的前 (k) 列。最小输入档位有一个成员达到原定的 800 轮上限。
- 每折固定预算集成取五个成员原始峰位预测的等权均值。正式参照取原先验证选出的十套配置，每套五个成员，共 50 个。原验证第一名的五成员对照沿用相同成员和完整输入，用于区分输入裁减和集成规模的影响。上节给出了两种模型都只用 64 列的另一次独立训练与比较。
- 核对了原始 50 成员集成的折外预测、全部 300 个新成员实际输入列名、种子、训练与验证 ID、验证 MAE 和权重文件。回放原 KAN 对照的 25 个成员，最大预测差小于 0.00063 cm⁻¹。五折的 1,265 个测试 ID 各出现一次，所有报告 MAE 可由同一张逐晶体预测表复算。[训练方案与每折列名](../benchmarks/phonons-mm-input-budget-20261114/protocol.json) · [成员核验记录](../benchmarks/phonons-mm-input-budget-20261114/model-audit.json)

在仓库根目录、原 `modnet-v012-matbench` 环境运行 `python scripts/benchmark_phonons_input_budget.py --workers 5` 可训练或复用已完成的成员，再运行 `python scripts/score_phonons_input_budget.py` 可重新计分和生成图表。[训练脚本](../scripts/benchmark_phonons_input_budget.py) · [计分脚本](../scripts/score_phonons_input_budget.py)

## KAN 同样在 64 个描述符下重新选择配置

2026-11-14 补充实验：与 MLP 的重选规则一致，在每个外折保留原 KAN 遗传搜索按内层验证 MAE 排名前十的候选记录。每套候选保持原来的两个隐藏层宽度、样条网格、学习率、输入缩放、目标标准化、随机种子和训练损失早停规则，只把输入改成该折与 MLP 完全相同的前 64 个描述符。每套训练五个内层成员，再按五个内层验证 MAE 的算术平均选一套；平局取原排名更靠前者。没有在 64 列下重新运行完整遗传搜索。
