# MatterVial phonons：数据审计与训练协议

本轮按用户要求先复现增强 MODNet，再使用相同特征、划分和受控训练预算比较分组稀疏 KAN 与等参数分组 MLP。2026-10-24 香港时间 00:28 已启动正式任务，PID 26668，初始使用 2 个 CPU worker。正式外层分数尚未产生；下面明确区分作者公开预测的复算、重新训练和协议修正后的对照。

启动前已通过 4 项完整性测试，以及含两种特征配置、共 88 次训练的端到端小规模验证。验证覆盖真实 XGB/NMI 对验证数据扰动的不变性、模型保存/加载、共享初始化、参数量、选择完整性和外层分数重算。小规模验证目录 `smoke-v1` 的成绩只证明执行路径可运行，不能作为性能结论。

## 已完成的核验

- 原始归档 10,724,277,360 bytes，SHA256 `855bb8928f3ba9292d37efdeac5b11291962447cd2302345bb11c53577627f6b`，提取 phonons CSV 后 SHA256 `6369c2322436adfaa29834b3e456192c73eab3d7da159f14c0a6102d91d0b535`。
- phonons 的 1,265 个样本全部与既有 Matbench 缓存核对：ID 对应、目标值、原子种类、晶格矩阵、分数坐标均一致。原缓存的 `id0...id1264` 按官方顺序映射为 `mb-phonons-0001...1265`，不按相似目标值匹配。
- CSV 共 5,624 个数值特征。论文 MM+MV 对应 4,738 列：MatMiner 2,059、MEGNet OFM 188、MVL16/32 288、ROOST mpgap 128、SISSO 283、ORB v3 1,792。不使用 ROOST oqmd 和 MEGNet MatMinerEncoded。去掉全部 SISSO 后为 4,455 列。
- 作者公开预测按官方五折重算 MAE 为 **30.08006109 cm⁻¹**，与作者记录 **30.08006080** 一致。各折为 35.212066、29.474083、32.433836、27.211150、26.069170，每折 253 个样本。**这只是复算作者预测，不是我们重新训练对齐了 30.08。**
- 独立环境 `modnet-v013-mattervial`：MODNet 0.1.13、TF 2.10.1、XGBoost 2.1.4、NumPy 1.23.5、pandas 1.5.3、scikit-learn 0.23.2、SciPy 1.9.3。MODNet 和 XGBoost 官方 PyPI wheel 均按 PyPI 元数据的 SHA256 校验。旧实验环境未修改。

审计数据保存在 `benchmarks/mattervial-phonons-20261023/audit`，包括固定版本的源文件、来源 URL/哈希、补充材料、公开预测验证和逐列特征清单。

## 泄漏核查：能确认什么

[论文补充材料](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41524-025-01938-2/MediaObjects/41524_2025_1938_MOESM1_ESM.pdf) S8、Table S12 说明：SISSO 前先用监督 XGB RFE 筛到 30 个主特征，再按与目标的相关性筛公式；公式来源任务包含 phonons、steels、dielectric。因此 **SISSO 公式的目标依赖已确认**。公开的 [公式调用代码](https://github.com/rogeriog/MatterVial/blob/0d17f9d24a7e0d982ab2845caf3205d520cccb08/mattervial/featurizers/sisso_featurization.py) 加载同一个固定公式库，没有外层折参数。

但公开资料没有提供公式产生时的逐样本 ID 和各外层测试折排除记录。SISSO 配置的随机 5% 留出不能自动视为 Matbench 的 20% 外层留出。结论是 **外层测试排除尚未获证据，不能默认无泄漏，也不能仅凭固定公式库断言论文的具体 30.08 成绩已经泄漏**。

可读取的 [其他数据集训练脚本](https://github.com/rogeriog/MatterVial_SupportData/blob/ccc65ab78daad3553468d393d4427936a0540b9f/other_datasets/jarvis_dft/masterscript_modnet.py) 在外层训练集上做 XGB/NMI，然后执行内层 CV；这段代码排除了外层测试，但内层验证标签可能参与此前的监督选特征。**这不是实际 phonons 训练入口，不能据此确定 phonons 的选特征范围。** phonons 日志在外层循环前读入一个预处理文件，第一折从 800 列开始，预筛选文件的拟合样本范围仍未确认。

补充材料 S13 报告 phonons 与预训练结构库较高的结构重叠。结构出现在预训练数据中不等于已确认目标标签泄漏。所有比较模型固定使用同一批外部表示，并报告外部预训练资源；预计算特征的提取时间未知，不能记为零。

## 本次冻结的执行协议

入口 `scripts/run_mattervial_phonons.py`；正式输出 `benchmarks/mattervial-phonons-20261023/run`。协议和源文件哈希写入 `protocol.json`，恢复时不接受变更。

1. **含 SISSO 的论文特征诊断**：使用论文相同的特征组、官方五个外层划分、MODNet 0.1.13、GA 种群 50 / 最多 20 代 / 连续 8 代早停、`refit=False`，每候选 5 个内层折，最终保留前 10 个配置的 50 个模型。
2. **无 SISSO 的主比较**：去掉全部 SISSO，使用相同预算重新执行增强 MODNet GA，再冻结每折的前 10 个主干模板用于三种模型的共同对照。不能只删除名称含 phonons 的 SISSO 列，因为跨任务样本重叠来源同样未核实。
3. 两阶段的 XGB RFE、特征间 NMI、目标 NMI 均只拟合各内层训练集。每轮 RFE 删除最低重要性的约 10%，最终保留 800 列，再执行原 MODNet 排序。所有缩放只拟合对应内层训练集。缺失/无穷值固定替换为 0，不拟合全数据统计量。

这比可用的相关作者脚本更严格；作者完整入口、随机种子和部分训练环境信息不可得。因此称为**论文配置的受审计复现尝试**，不宣称完全逐位复现。含 SISSO 的分数只用于诊断，不能作为无泄漏 KAN 优势的依据。预先定义相对 30.08006 的 ±2% 为“数值接近”的描述阈值，不表示统计等价，也不据外层成绩继续调参。

### KAN / MLP 受控阶段

- 三种模型为增强 MODNet、增强 MODNet + 分组 MLP、增强 MODNet + 分组稀疏 KAN。
- 每个共同模板都使用相同的 NMI 核心特征与固定 16 个物理描述符的去重并集。模块从这 16 个物理量产生 4 个额外特征；各组定义沿用前一轮先验，没有按外层测试重选。
- 分组 MLP 和 KAN 模块均为 148 个可训练参数；相同模板/内层折的完整模型参数量也严格相等，最终 50 成员集成总参数量相等。MODNet 基础对照的参数量单列。
- 10 个模板 × 3 个学习率倍数（0.5、1、2）× 5 个内层折 = **每种模型 150 次训练，每个外层折三种模型共 450 次**。各模板分别按五折内层平均 MAE 选学习率，保留所有 10 个模板的 50 个成员。
- 三种模型均固定训练集 minmax 缩放到 [-0.5,0.5]，使用配对种子和相同 Dense 主干初始权重，Adam、原尺度 MAE、最多 800 epochs，训练 MAE 早停（patience 30，min_delta 0.001，不恢复最优权重）。模块正则化不改变早停监视量。
- KAN 为固定 5 区间三次 B 样条加线性分支，平滑强度 0.001、软边/组稀疏强度 0.01，正则项按训练目标标准差缩放。它是分组加性模块，不能把此处结果解释为 KAN 独有的组间交互能力或精确剪枝。
- 受控阶段统一使用原始网络预测；GA 复现另存 MODNet 原有异常预测替换前后的成绩，避免随机替换掩盖差异。

**预算的边界**：150 次/模型是受控阶段相同的训练次数和 epoch 上限，早停后的实际时间可能不同。前面的 MODNet GA 是三种模型共同采用的主干发现成本，单独报告，且其搜索方向偏向 MODNet；不能声称三种方法从零开始的全部超参优化成本相同。

所有控制模型的特征、划分、种子、容量与完整内层结果检查通过后，先写出冻结选择文件，再读取外层测试预测。输出包括逐折/逐成员 MAE、参数量、选中模型训练时间、全部搜索时间、特征筛选时间及实际成员数。

## 已有物理模块小试验

前一轮独立的 100 次小试验已完成，只使用 phonons 第 1 外层折训练部分的内层验证。两种子集成 MAE：MODNet 37.685916、相同物理输入 38.676154、分组 MLP 38.112861、样条 37.942097、分组稀疏 KAN 38.097919。该结果尚未显示 KAN 超过原 MODNet，不能直接和五折外层 30.08 或 34.01 相减。它没有包含本轮 MatterVial 增强输入。

## 运行与恢复

```powershell
./scripts/start_mattervial_phonons.ps1 -Jobs 2
```

进程隐藏启动，日志直接写盘，断点按候选模型恢复。正式试验默认先完成五折含 SISSO 诊断，再执行五折无 SISSO 的主比较。`--smoke` 使用独立目录、少量固定特征、1 epoch 和缩小 GA，只用于验证完整执行路径，禁止汇入正式成绩。

完成某些外层折后，可用以下命令核验并汇总已有结果；未完成的折不会混入完整五折均值：

```powershell
& "$env:USERPROFILE\.conda\envs\modnet-v013-mattervial\python.exe" scripts/report_mattervial_phonons.py
```
