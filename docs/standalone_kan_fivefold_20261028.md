# 增强特征完整 KAN：冻结后完成官方五折评估

本轮按用户要求只运行增强特征组，复用已核验的第1个外层折（代码编号 0），新增其余四个外层折（代码编号 1–4）。四折全部计入最终结果，不按内层成绩或外层输赢筛掉任何折，也不根据已见的外层成绩改变配置。

## 冻结配置与同等预算

完整 KAN 为 256→17→8→1，35,994 参数；近线性 Greville 初始化、三次 B 样条、固定网格、隐藏逐维 0.5*tanh，均沿用第1折。等参数 MLP 为 256→96→72→36→45→1，35,995 参数，固定 ELU。无 SISSO、无残差 KAN、无新增正则或结构搜索。

每个外层折有 1,012 个训练样本和 253 个测试样本。只复用官方划分 ID，不复用旧实验筛选的特征。各折分别创建不含本折测试行的训练缓存，并重新做训练范围内的 XGB gain 排序：固定16个物理特征＋其余前240个特征。输入 minmax 与目标均值/标准差都只拟合相应训练范围。

保持第1折的调参规则：对外层训练数据按冻结的 `make_splits` 生成五组内层划分；每组的训练部分再取固定20%作为调参验证集。因此每次调参训练约647–648个样本、验证162个样本，和第1折一致，不悄悄扩大为另一种内层预算。

双方各试学习率 0.0005、0.001、0.002，种子480281、481281（加内层折号），五组划分共30次调参/模型/外层折。Adam、batch32、最多400轮，内层验证MAE早停 patience40、min_delta0.05 cm⁻¹，恢复精确最低验证MAE权重。

各模型独立选择五组划分×两种子的平均内层验证MAE最低的学习率；平分选较小学习率。完整外层训练轮数为该学习率10次最佳轮数的中位数、四舍五入。全外层训练集重新筛选和缩放，再用固定种子680281、681281各重训一次。外层数据不参与早停或checkpoint选择。

每个外层折共60次调参＋4次重训＝64次；剩余四折新增256次。五折核心比较共320次，双方各160次。过去的独立确认、物理输入组和其他探索计算另列，不混入这320次的对应模型训练耗时。

## 汇总规则

- 主指标：每折固定两个种子等权平均预测后的外层MAE，再对五折MAE取平均；同时报告折间样本标准差（ddof=1），不称置信区间。
- 附指标：两个单种子的五折成绩及单模型平均MAE。禁止选最好的种子作为该模型成绩。
- 每折列出 KAN、MLP、绝对改善（MLP−KAN，正值有利于KAN）、相对改善和胜负；生成覆盖1,265个样本的完整折外预测，检查每个样本仅作测试一次。
- 单模型参数量与双模型集成总参数量分别报告。
- 每折、每个模型分别汇总30次调参任务和2次外层重训任务的累计耗时。预处理耗时为共享成本，单列；并发worker耗时不能当作实际等待时间相加。任务耗时包括模型构建、预测与保存，不冒充纯 `model.fit` 时间。
- 第1折的原始整体墙钟包含物理组和确认阶段，不能与新四折核心比较墙钟直接相加。新四折墙钟独立报告。

## 结果解释边界

前期结构选择使用过第1外层折的训练样本，这些样本与其余外层折的测试样本有重叠；扩展也是在看到第1折结果后决定的。因此这是冻结方法后的完整五折评估，不能称为整个开发过程从未触碰过的独立外部确认。当前每一折的特征筛选、缩放、超参数和轮数选择严格隔离于该折外层测试数据。

预训练特征的来源限制继续保留。无论最终是否整体改善，保留并汇总全部五折，后续改动需要新的实验协议。原有正式 MODNet/MatterVial 复现进程和已完成的第1折结果保持不变。
