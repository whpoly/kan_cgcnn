## 配对条件与代价

- 使用同样的官方特征、外层与内层样本划分、成员种子、宽度、优化器、学习率、batch size、早停规则以及 50 成员集成。KAN 沿用 MODNet GA 选出的配置，没有单独调参。
- 本轮 KAN 是 Gaussian RBF FastKAN，不是原始 B-spline KAN。输出头版本只替换最后一层；全 KAN 替换全部五个 Dense 层。
- 全 KAN 的平均单成员参数量约为 MODNet 的 4 倍，因此属于同宽度替换实验，不是等参数量比较。
- steels 平均单成员参数：MODNet 66,523；输出头 KAN 66,795；全 KAN 265,660。phonons 对应 106,285、106,531、425,370。
- 已选中集成成员的累计训练用时比：steels 输出头 1.15 倍、全 KAN 1.51 倍；phonons 输出头 1.21 倍、全 KAN 1.92 倍。这不含 MODNet GA 搜索代价，也不是独立重复测量的运行速度基准。
- 保留原版预测时对极端越界值的随机替换行为。steels 全部五折的成员预测替换数分别为 MODNet 28、输出头 66、全 KAN 7；phonons 均为 0。原始与后处理预测均已保存。
