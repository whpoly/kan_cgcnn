**正式 phonons 高精度 KAN 的物理中间量与 MLP 对照，2026-11-06**

找到的最可靠线索是“几何尺度相关表征”：高精度 MM+MatterVial KAN 的第一层存在跨折重复出现、与平均键长及每原子体积稳定对应的节点；深层表示也比对应 MLP 保留了更多可线性读出的几何信息。这个优势有范围限制：它不等于发现了独立的键长机制、有效质量或力常数，MLP 中也存在几何相关节点。

本报告只分析 `native-fourway-scaled-kan-20261029` 正式 phonons benchmark 的已有权重。没有使用小型物理 KAN 的曲线、贡献或成绩来解释这些模型，也没有修改、重训网络。物理量的仿射标定与线性探针是分析工具，不替代原预测器。

| 正式五折模型 | MAE，cm⁻¹ | 本次检查成员数 |
| --- | ---: | ---: |
| MM + MLP/MODNet | 33.927645 | 250 |
| MM + KAN | 29.448984 | 250 |
| MM + MatterVial + MLP/MODNet | 28.757824 | 250 |
| MM + MatterVial + KAN | 28.227439 | 250 |

四组共 1,000 个成员，均覆盖全部五折、每折全部 50 个成员。每折成员来自十个选中候选的五个内层拟合，不能当成 50 份独立实验。所有成绩均使用原始成员预测的平均值；重新加载权重与保存外层预测的最大偏差为 0.001836 cm⁻¹，原五折 MAE 已复核。

**对应物理量的方式。** 对平均原子质量、平均半径、半径偏差、平均键长、结构内平均键长标准差、每原子体积、平均电负性、电负性差、Voronoi 配位数、密度，以及两个固定变换 `1/sqrt(mean_mass)`、`vpa^(-1/3)`，使用完全相同的分析流程。

每个成员仅在其实际训练样本上选择与指定物理量绝对 Pearson 相关性最大的隐藏节点，并拟合 `q_hat = a + b*h_j`。对应关系、符号方向、a、b 均在检查外层样本前固定。使用该折 253 个外层留出材料检验相关性和物理量读出 R²。这里的 R² 衡量隐藏表示能否恢复描述符，不是声子频率预测 R²。

本轮预设“强对应”为外层 |r|≥0.8 且仿射读出 R²≥0.5；“跨折稳定”为五个折各自至少 70% 的成员满足强对应。阈值是描述性判据，不是显著性检验。候选节点以物理量对应关系跨模型对齐，不按节点编号对齐。

第一层取原生层输出。深层取 KAN 最后样条层之前的隐藏输出；MLP 取最后一个非线性隐藏层输出，并将后面的连续线性层合并。这避免把 MLP 任意线性重参数化后的中间基当作独立物理节点。两种架构的层级并不完全等价，因此结果限定为当前保存模型的表示。

**最具代表性的原生节点是增强 KAN 的几何尺度通道。** 以下 R² 是五折“成员 R² 中位数”的平均，每折通过比例使用该折全部 50 个成员。

| 第一层对应量，MM+MatterVial | KAN 物理量读出 R² | MLP 物理量读出 R² | KAN 每折通过比例 | MLP 每折通过比例 |
| --- | ---: | ---: | --- | --- |
| 平均键长 | 0.716 | 0.709 | 100%、90%、94%、100%、98% | 96%、86%、90%、96%、90% |
| 每原子体积 | 0.697 | 0.658 | 96%、94%、78%、96%、84% | 76%、74%、68%、76%、74% |
| 每原子体积的负三分之一次方 | 0.706 | 0.707 | 96%、86%、90%、84%、98% | 84%、88%、80%、94%、92% |

第三项是几何长度的倒数代理，与平均键长和体积高度关联；这三项不是三个独立物理机制。MLP 在键长和逆长度上同样通过稳定性判据。KAN 的体积对应度略强，但不能把一个 70% 阈值两侧的差别直接当作显著性。

![原生几何节点对照](../benchmarks/formal-phonons-concepts-20261106/geometry-native-evidence.png)

固定选择第 0 外层折、保存列表第 0 个成员作为可复查例子，不按测试成绩选择。增强 KAN 第一层 `h[29]`（零起始编号，即第 30 个节点）的标定为：

`mean_bond_length_hat [Å] = 3.69584248 − 0.172547743 × h[29]`

`volume_per_atom_hat [Å³] = 40.4720965 − 3.59788772 × h[29]`

两者外层 R² 分别为 0.779801 和 0.787976。该坐标较大时，平均键长和每原子体积倾向于较小，因此可以称为“几何尺寸/紧致度相关坐标”。它不是只含键长信息的纯坐标，也不意味着所有折的第 29 个节点都有同样含义。

同一个固定示例的 MLP 节点分别为 `h[74]`（键长读出 R²=0.686898）和 `h[263]`（体积读出 R²=0.649530）。单个示例的差值不替代上表全部成员、全部折的比较。另一个增强 KAN 节点 `h[40]` 对逆长度代理的标定为 `vpa^(-1/3) = 0.316767230 − 0.013643548*h[40]`，外层 R²=0.782245。

这几个 h 都是原网络已经存在的激活。原生 KAN 节点的计算仍是 `bias + sum_i sum_k c[i,k]*B_k(scaled_x[i])`，并保留原来的逐列缩放和必要的逐坐标 tanh。每条输入边的 8 个系数、结点序列、偏置、输入名字、缩放参数已经导出到 `geometry-native-weights.json`。从这些权重复算示例节点的最大误差为 1.10×10⁻⁵。

该示例 h[29] 的输入边绝对中心化幅度之和，约 67.3% 来自 MatterVial 嵌入，31.6% 来自其他 matminer 描述符，1.1% 来自本次明确命名的十个物理描述符。这个比例不是解释方差或因果份额，但说明不能把 h[29] 简化描述成“平均键长输入的一条边”。它的几何含义来自外层材料上的对应检验，内部仍混合了复杂表示。

**这些通道参与正式预测，但删除实验不能等同于物理干预。** 将每个成员的训练选定“键长对应第一层节点”替换为该成员训练均值，并保持其他节点和权重不变，增强 KAN 的五折平均 MAE 从 28.227 增至 39.741 cm⁻¹，平均增量 11.513，五折均变差。体积对应节点的平均增量为 9.104 cm⁻¹，也为五折均变差。

MLP 的对应增量分别为 0.665 和 1.181 cm⁻¹。不能直接把更大的 KAN 增量称为更正确的物理作用：增强 KAN 第一层平均约 32.1 个节点，MLP 为 220.8 个，单节点承载的信息量和冗余程度不同。节点替换还可能进入非自然激活状态，同时移除其携带的其他信息。这个实验支持“该几何相关通道对原预测有用”，不测量真实改变键长或体积的材料响应。

**深层的主要优势是几何信息仍然可读出。** 对每层全部隐藏激活拟合固定惩罚系数 0.01 的线性岭回归，输出真实物理描述符；所有拟合只用该成员训练样本。以下是按整层共享 RMS 尺度归一化后，成员读出结果取集成平均的五折平均外层 R²。

| 深层读出的物理量 | MM MLP | MM KAN | MM+MV MLP | MM+MV KAN |
| --- | ---: | ---: | ---: | ---: |
| 平均原子质量 | 0.619 | 0.774 | 0.618 | 0.658 |
| 平均共价半径 | 0.744 | 0.861 | 0.702 | 0.773 |
| 平均键长 | 0.751 | 0.882 | 0.743 | 0.805 |
| 每原子体积 | 0.717 | 0.874 | 0.724 | 0.809 |

MM 组这四项均为 KAN 五折全部较高；增强组几何三项为四折较高。平均键长读出的平均折 RMSE，MM 组为 MLP 0.226 Å、KAN 0.155 Å，增强组为 MLP 0.229 Å、KAN 0.198 Å。上述读出只是对原隐藏量的分析，不参与或替代声子预测。

为检查维度差异，另将两类网络都限制为各自训练激活的前四个主成分，使用相同线性读出。MM 组键长 R² 仍为 KAN 0.743、MLP 0.683；增强组为 KAN 0.720、MLP 0.682。半径、键长和体积在两组输入下均为 KAN 五折全部较高。这支持几何信息保留的有限优势，并非仅由读出维度更多造成。它仍不隔离输入筛选、训练结果与表示形式等因素。

增强组的质量在四维对照中为 KAN 0.553、MLP 0.557；倒平方根质量则为 KAN 0.490、MLP 0.528。质量相关量不支持同样的普遍优势。第一层的全表示物理量读出多数又是 MLP 更好，说明不能把深层结果推广成“每一层、每个物理量都更可解释”。

![稳健物理量读出对照](../benchmarks/formal-phonons-readout-robustness-20261106/robust-readout-comparison.png)

只使用网络最终预测值做相同的仿射物理量读出，键长 R² 只有约 0.30、体积约 0.24—0.25。深层几何读出明显超过这个对照，因此并不只是利用“高频/低频材料往往有什么尺寸”的单一关联。与此同时，增强 KAN 深层平均约 15.1 个节点，MLP 约 87.2 个；MM 组分别为 22.3 和 75.4 个。当前 KAN 的表征更窄，但各组独立选择了输入和结构，不能由此建立一般性的架构因果结论。

**数值稳健性检查保留了不利结果。** 最初逐节点标准差归一化的线性探针，在 9 个 MLP 成员上出现至少一项 R²<-100。检查发现有几乎不变的训练通道，训练尺度接近 10⁻⁸，外层激活却发生变化；按该小尺度归一化会严重放大外推误差。一个案例的最大外层单位标准化偏离超过 119 万。

原始探针、参数和失效结果均保留，未用于宣称 KAN 大幅领先。后续固定的整层 RMS 尺度对照不再单独放大小方差通道，并加入四主成分对照。这一稳健性检查是在看到初始探针失稳后启动的探索性复核，不冒充事先完全盲定的确认实验。修正后 MLP 读出恢复正常，上表的几何信息优势仍然保留。

**为什么还不能把这些量称为独立物理机制。** 本轮进一步分别用训练数据拟合并扣除最终预测值，以及其他物理家族描述符的线性关联，再检查外层偏相关。要求对应节点同时在这两个检验中达到 |r|≥0.5，且五折各有至少 70% 成员通过时，四组模型均没有候选通过。

例如增强 KAN 示例 h[29] 的键长对应关系，在扣除预测值后外层偏相关绝对值仍为 0.854，说明它不仅是输出频率的副本；扣除其他物理描述符后降至 0.305。体积相应从 0.870 降至 0.340。这支持“混合的几何相关表征”，不足以唯一归因为键长或体积。偏相关本身也只排除指定的线性关系，不能证明因果。

所有组的深层都没有满足上述跨折稳定标准的强单节点物理候选；较好的多节点读出表示物理信息分布在多个节点中。明确命名的量主要在第一层出现。当前数据没有提供可校验的模态本征矢或力常数矩阵，因此不能给任何节点直接贴上有效质量或刚度标签。声子频率来自质量加权动力学矩阵的本征值，平均原子质量和尺寸代理不等于这些模态量。[Phonopy 公式](https://phonopy.github.io/phonopy/formulation.html#dynamical-matrix)

物理概念与节点对应的检验借鉴了“检查隐藏单元与外部概念是否对齐”的一般思路，本报告采用连续描述符的训练标定和外层验证，不是图像 Network Dissection 的复现。[Network Dissection 原论文](https://arxiv.org/abs/1704.05796)

**可以支持的研究表述。**“正式高精度 phonons KAN 中存在跨折稳定、参与预测的几何尺度相关原生通道。与保存的 MLP 对照相比，KAN 在较窄的隐藏表示中保留了更多可线性读出的几何信息，该趋势在统一四维读出下仍存在。当前证据支持几何表征的可读性和紧凑性，尚不支持独立物理机制、有效质量或力常数的识别。”

五折稳定性仍来自一个数据集，训练集间有重叠，且旧 benchmark 已被查看；这是对既有结果的事后解释研究。下一步若验证物理机制，应围绕相关几何量进行结构可实现的扰动，或提供独立力常数/模态数据校验。本次没有进行新训练或新物理计算。
