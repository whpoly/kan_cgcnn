# KAN 能把材料响应的转折定位到一条连接

2026-11-12。钢的一个正式 KAN 成员在“钛原子含量 → 第一层节点 11”的单条连接上，学到了先升后降的响应。根据原样条的导数，局部峰位在 **0.459 at.% Ti**。可以指出产生这段弯曲的模型参数，改变其中一个，再用原网络检验预测怎样变化。这为以前的三个特征贡献分解增加了一个带材料单位的可解释量，即**某条模型响应改变方向时的输入值**。[以前的物理输入分解](kan_native_physical_responses_20261112.md)

## 两种架构分别允许读出什么

固定其他输入并改变一种元素的成分 $x$。本项目的 KAN 节点收到的这一项是 $\phi(T(x))$，其中 $T$ 为训练好的输入变换，$\phi$ 是这条边自己的三次样条。输入缩放、可选的双曲正切和截断都保持次序，方向反转发生在样条上。$\phi'$ 为零且两侧符号相反的位置可换算回原子百分比或 pm。节点其他输入对这条曲线相当于一个常数平移。[本项目的样条实现](../scripts/standalone_kan_models.py) · [KAN 原论文](https://arxiv.org/abs/2404.19756)

本次 500 个配对 MLP 的第一层全部使用 ELU。对单个节点，固定背景 $b$ 后，响应为 $\mathrm{ELU}(b+wT(x))$。输入缩放单调递增，ELU 也单调递增，因此这个节点沿 $x$ 的方向由 $w$ 的符号决定。完整 MLP 能通过多个通路的组合形成峰谷。两种模型的差别在于，KAN 可以把一个非单调响应完整放在一条可命名、可检查的输入边上。这里按能在原网络中指认的部件计数，每条 KAN 边有 8 个样条系数，MLP 的一条输入边有 1 个标量权重。[ELU 的原始定义](https://arxiv.org/abs/1511.07289)

## 钢中的钛曲线

选择规则使用训练信息。沿用之前每对模型共同选出的三个具名输入，从出现合格转折次数最多的直接元素原子分数中取例，按折号和成员号取第一个合格成员。得到第 0 折、第 18 个成员的 Ti 边。横轴以 at.% 为单位，0.5 表示钛原子占比为 0.5%。两种模型分别使用自己的节点激活刻度。

| 三个训练材料中实际出现的 Ti 含量 | 0.000 at.% | 0.494 at.% | 0.978 at.% |
| --- | ---: | ---: | ---: |
| KAN 节点 11 上 Ti 边的变化，相对第一点 | 0 | +0.296 | −0.022 |
| MLP 节点 193 的变化，留出背景中位数 | 0 | +0.254 | +0.504 |
| 完整 KAN 强度预测的变化，留出背景中位数 | 0 | +26.43 MPa | +9.05 MPa |
| 完整 MLP 强度预测的变化，留出背景中位数 | 0 | +55.95 MPa | +120.21 MPa |

后两行改变 Ti 描述符通往所有节点的输入。同一留出材料的其他描述符始终取原值，差值先在各自材料上计算。这个 KAN 成员的 63 个留出背景中，48 个在三个位置的完整预测出现中间高于两端各 1 MPa 以上，1 个出现反向的谷。只在节点 11 上把这条边的左右两端用直线相连，则 63 个真实留出输入上最终预测的平均绝对变化为 **0.426 MPa**。整条 Ti 输入通向多个节点，表中的 +26.43 MPa 包括这些通路。[示例的曲线、原始位置和干预结果](../benchmarks/kan-native-turns-20261112/steel/fold-0/member-18.json)

### 可以从权重写出这段曲线的公式

记 $x$ 为表中使用的 Ti 原子百分数，$q(x)$ 为这一条边相对 $x=0$ 的响应。在包含峰的 **0.23934 至 0.50757 at.%** 这一段，直接把原样条展开可得下式，展示系数作了舍入。

$$
u=\tfrac12\tanh(1.511624\,x-0.564526)-0.064547,\qquad
q(x)=0.300492-6.245273\,u^2-10.333985\,u^3 .
$$

$u=0$ 对应 **0.45934 at.%**。这里一阶导数为零，二阶项为负，因此是局部峰。该三次式来自已训练模型对应样条区间的精确展开，用未舍入系数在本段 251 个位置和原函数逐点核对。相邻样条区间有各自的三次式。[公式与逐点复算误差](../benchmarks/kan-native-turns-20261112/summary.json)

还可以直接编辑这个模型。把该边的第 5 个样条系数减小 0.24173，三个观测位置中，中间点高出两端连线的幅度从 **0.30720** 下降为 **0.15360** 个激活单位。新幅度以编辑后的两端重新计算，两端本身也可能移动。63 个钢样上的最终预测平均绝对变化为 **0.126 MPa**。修改在内存中的原 Keras 层上核验，完成后恢复权重。

## 两项任务中有多少这样的边

钢使用 SHAP Top-50 正式模型，声子使用 MM + MatterVial 正式模型。每项任务覆盖五折、每折 50 对训练样本相同的 KAN 和 MLP。沿用各对模型先前只用训练数据选出的三个具名输入和接收节点，新分析从每项任务 750 条输入边中查找转折。成员会共享训练材料，同一个描述符也可以重复出现。

| 每项任务 750 条入选边 | 钢屈服强度 | 声子态密度末峰 |
| --- | ---: | ---: |
| KAN 的训练支持区间内有明显转折 | 370（49.3%） | 254（33.9%） |
| 其中在留出材料实际出现的输入值上仍能读到同方向的转折 | 345 / 370 | 253 / 254 |
| 至少有一条合格边的 KAN 成员 | 199 / 250 | 154 / 250 |
| 配对 MLP 的单个第一层节点在固定背景下能出现的内部转折 | 0 | 0 |
| 把显著幅度门槛从 15% 改为 10% / 25% 后，KAN 合格边数 | 407 / 297 | 299 / 192 |

“明显转折”要求从原样条导数找到驻点且确认两侧斜率换号。在训练集第 10 至 90 百分位内，用实际出现的左、近中、右三个输入值检验，两侧较小的起伏须达到该边中央区间完整响应跨度的 15%。驻点两侧各须有至少 8 个训练样本且占该成员训练样本至少 5%，每侧至少两个不同输入值，驻点附近须有至少三个训练样本。外层核对另要求两侧各至少三个留出样本、中间有邻近观测值，且同方向起伏达到训练跨度的 10%。这里的留出支持指对应横坐标在留出材料中出现，核验对象是固定权重的节点响应。

### 哪些位置会重复出现

**钢的 Ti。** 在 61 条入选 Ti 边中有 41 条通过转折标准，35 条得到留出输入支持。41 条中有 11 个隐藏峰和 30 个隐藏谷，五折各有 1、6、17、4、13 条。它们的转折位置中位数为 **0.449 at.%**，四分位区间为 **0.373–0.529 at.%**。对各成员自己的三个输入位置，完整 KAN 在过半数留出背景上呈明显峰的有 18 个，呈明显谷的有 5 个。阈值指中间点与两侧分别相差超过 1 MPa。单个节点的方向、大小，以及后续网络给它的权重，会影响完整输出的方向。

**声子的最小共价半径。** 该量在 65 个成员中入选，24 条边出现转折，23 条得到留出输入支持。转折位置中位数 **80.7 pm**，四分位区间 **77.0–91.5 pm**。按训练规则取到的第 0 折、第 10 个成员在 **73.45 pm** 有局部峰。对这一成员，在 57 至 77.8 pm 的样条区间，令 $u=R-73.4481$，相对 57 pm 的响应为 $q(R)\approx0.0130228-0.0000619745u^2-0.000000841323u^3$。半径取自材料组成中元素的共价半径表，连续峰位是样条在这些离散取值之间的插值。把整个转折区间在所选边上拉直，预测平均绝对变化为 **0.057 cm⁻¹**。[声子固定示例](../benchmarks/kan-native-turns-20261112/phonons/fold-0/member-10.json)

**先前的 Mo 示例。** 第 0 折、第 0 个钢成员中，Mo → 节点 23 的曲线在训练中央区间 0.175–3.060 at.% 内保持单调。这条曲线仍然给出浓度敏感区间。绝对斜率最大处约在 **2.07 at.%**，达到最大斜率 80% 的连续区间为 **1.87–2.31 at.%**。最大局部斜率约为每个原子百分点 0.358 个激活单位，包含原网络的输入缩放。换算成 MPa 需要继续经过后续层。

### 样条本身也容易产生转折

针对 Ti 和最小共价半径，保留每条边的训练输入分布、缩放、样条结点及 8 个已训练系数的数值，随机打乱系数次序。对全部入选该特征的成员独立打乱，重复 200 次，每次重新运行相同检测。这个对照同时改变了曲线的平滑程度，分布用于描述网格和输入支持可能造成的聚集。

| 控制量 | Ti 原模型 | Ti 打乱后中位数 | 最小半径原模型 | 最小半径打乱后中位数 |
| --- | ---: | ---: | ---: | ---: |
| 合格转折边数 | 41 / 61 | 41 / 61 | 24 / 65 | 47 / 65 |
| 跨成员转折位置中位数 | 0.449 at.% | 0.424 at.% | 80.7 pm | 95.0 pm |
| 跨成员转折位置四分位区间的宽度 | 0.156 个百分点 | 0.314 个百分点 | 14.6 pm | 22.3 pm |

Ti 打乱对照的 200 个位置中位数，其第 5 至 95 百分位为 0.351–0.512 at.%，包含原模型的 0.449 at.%。原模型的转折位置比这种打乱对照更集中。记录到弯曲、能读出弯曲、证实材料中的强化机制是三个不同问题。实际合金的最优 Ti 含量仍需成分、热处理与组织受控的独立力学数据。[钢的打乱结果](../benchmarks/kan-native-turns-20261112/steel/coefficient-order-control.json) · [声子的打乱结果](../benchmarks/kan-native-turns-20261112/phonons/coefficient-order-control.json)

## 同样检验完整 MLP 和完整 KAN

为避免只在 KAN 已知转折处测试，另对全部预先选中的输入使用相同网格。取训练集 10%、30%、50%、70%、90% 分位对应的实际观察值。对每个留出材料的其余输入，分别运行两个完整网络，检查相邻三个不同输入的中间点是否比两侧都高、或比两侧都低。两侧差值都须超过 1 个目标单位。计数单位是“成员、输入、留出背景、三点区间”组合，同一材料可参与多次。

| 公共网格检验 | 钢，136,601 个组合 | 声子，491,326 个组合 |
| --- | ---: | ---: |
| 完整 KAN 输出有显著转折 | 40,665 | 69,489 |
| 完整 MLP 输出有显著转折 | 1,534 | 4 |
| KAN 完整输出的转折中，同时能在指定首层节点读到转折，且隔离该节点路径后输出仍同向转折 | 5,676 / 40,665（14.0%） | 5,128 / 69,489（7.4%） |
| MLP 在同一单节点定位条件下通过 | 0 / 1,534 | 0 / 4 |

此处的“定位”要求首层节点值在三点之间确实反转，而且只把该节点随输入的变化送进后续层时，预测仍同向反转且超过 1 MPa 或 1 cm⁻¹。每组只检查事先选中的节点，因此这些比例衡量该条路径覆盖的范围。改变一个输入并保留全套其他描述符，可以构造某些不满足真实成分相关关系的组合。表中统计限于网络响应。

**原预测究竟依赖这些转折多少。** 每个成员选取原先三项排序中首条合格边，仅在训练确定的左右端点之间，以两端连线替换原响应。对配对 MLP 使用相同输入和区间，连线两端使用各材料自身的背景。没有合格边的成员沿用原预测。对真实留出材料，钢 KAN 集成的 MAE 从 **84.9630 变为 84.9918 MPa**，配对 MLP 从 86.4381 变为 86.4582 MPa。声子 KAN 从 **28.2274 变为 28.2226 cm⁻¹**，配对 MLP 从 28.75782 变为 28.75787 cm⁻¹。每次只修改一条边的一个区间，集成误差的变化很小。该证据支持从原参数定位、量化和干预模型内部的非线性响应。用这些单边转折解释整体预测精度差异，现有对照还不充分。
