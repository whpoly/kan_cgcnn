# 完整 KAN 替代 MODNet：冻结的小规模验证协议

2026-10-27，用户明确要求直接用 KAN 代替 MODNet，不继续残差方案。本轮所有 KAN 候选均独立完成从输入到标量输出的预测，不含 MODNet 主干、MLP/Dense 层、跳接或 SiLU 基础分支。

MODNet 的名称包含整个材料学习流程。本轮替换的是预测网络，保留前轮已审核的特征与划分，以便把网络结构差异和输入信息差异分开检验。

## 结构和配对

| 输入组 | 模型 | 结构 | 参数量 |
| --- | --- | --- | ---: |
| 256 个无 SISSO 增强特征 | MODNet | 256→96→72→36→36→1 | 35,653 |
| 同上 | 配对 MLP | 256→96→72→36→45→1 | 35,995 |
| 同上 | 完整样条 KAN | 256→17→8→1 | 35,994 |
| 同上 | 完整样条 KAN，稀疏＋平滑 | 同上 | 35,994 |
| 固定 16 个物理描述符 | 配对 MLP | 16→75→27→1 | 3,355 |
| 同上 | 完整样条 KAN | 16→17→8→1 | 3,354 |
| 同上 | 完整样条 KAN，稀疏＋平滑 | 同上 | 3,354 |

每条边是 8 个三次 B 样条的线性组合，每个节点对入边函数求和并加偏置。网格固定为 [-0.5,0.5] 上五段。第一层输入使用原有训练集拟合的逐列 minmax 缩放；后续边函数内部使用逐坐标 `0.5*tanh` 将隐藏坐标映射到网格范围。这是参数固定的一维坐标变换，不混合变量，不增加跨层支路。

稀疏版本对去掉系数均值后的边系数 RMS 加 0.001 的惩罚，对系数二阶差分均方加 0.001 的平滑惩罚。二者作为固定联合消融，不能单独归因于稀疏或平滑。无正则版和正则版初始权重、种子一致。固定网格和正则系数不在本轮搜索。

与此前 16→1 加性/乘积小模型不同，本轮物理 KAN 是多层组合模型，能够表示更一般的非线性相互作用。它的容量也更大；所有结论应以本轮配对 MLP 为对照，不能将新旧成绩变化全部归因于 KAN。

## 数据和训练

复用 `mattervial-quick-pilot-20261026` 已审核的五个内层输入；只涉及第一外层训练折的 1,012 个样本，全部排除 SISSO。特征筛选、缩放、目标标准化均限定于每个内层训练集。256 输入组和 16 输入组信息量不同，结构优势只能在各自组内判断。

七个配置 × 五个内层折 × 两个种子 = 70 次。基础种子为 20261027、20271027，每折加折编号；它们与前轮相同，用于配对，不声称新的独立确认。全部重新训练，包括 MODNet 参考。

Adam、学习率固定 0.001、batch 32，最多 400 轮。内层验证 MAE 早停 patience 40，min_delta 0.05 cm⁻¹，恢复精确最低验证 MAE 的权重。目标按训练均值/标准差归一化，报告时转回 cm⁻¹。这是统一预算初筛，不保证学习率、网格、深度对每种模型都最优。禁止根据外层测试调整配置。

## 对整个 KAN 做解释性检查

- 导出每一层全部边函数和节点偏置，验证用独立 NumPy 实现可重建网络输出。
- 只用内层训练激活计算每条边的响应均值/标准差。边响应标准差小于该层最大值 5% 的边作为剪枝候选；剪掉时将该边训练均值补入节点偏置，随后评估整个剪枝网络在验证集上的 MAE。此为掩码消融，不冒充已压缩模型文件。
- 在训练边坐标上，用固定的常数、线性、二次、三次多项式近似边响应。只接受 RMSE 不超过该边训练响应标准差 5% 的最简函数，否则保留样条。替换后必须重新从原输入运行整个网络，报告最终误差和预测偏移；不能只报告单条边的拟合优度。
- 物理输入组可对具名物理量计算模型响应曲线，跨折、跨种子比较同一输入对最终预测的影响。隐藏节点可交换、变号或重构，不能直接按隐藏节点编号比较物理作用。

增强特征中有预训练模型嵌入，因此完整 KAN 的函数图可检查，不等于整条计算路径具有明确的物理单位。只含物理描述符的 KAN 更适合提出物理假设，但相关输入和训练数据的局限仍然存在。不要把隐藏节点直接命名为力常数或振动有效质量。

本轮不读取外层测试，也不沿用旧版“全 KAN 在 phonons 上 33.02”的数值作直接比较；旧版为不同输入协议的 Gaussian FastKAN，同宽度下约四倍参数量，和本轮不是同一实验。
