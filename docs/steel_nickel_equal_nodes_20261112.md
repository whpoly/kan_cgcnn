# 同两种钢、同一镍当量变化，三个第一隐层节点能解释多少

> **更正（2026-11-12）**　下文的 Ni 替 Fe、C 替 Fe、节点替换及背景移植属于模拟。此前依据它们推断镍当量对真实钢材强度的影响、或比较两模型在真实钢材上的解释可靠性，这些结论已撤回。原始钢样、实测强度和同预算节点的复核见[真实钢样对照分析](steel_observed_pairs_20261112.md)。

主检验从同一张真实配方出发，用 1 个质量百分点的 Ni 等量替换 Fe，保留其余元素的质量百分数。对钢 005，Schaeffler 镍当量从 19.719 变到 20.719，对钢 020，从 4.405 变到 5.405。给 KAN 和 MLP 输入完全相同的配方变化，分别计算完整网络的屈服强度预测差。接着只让三个第一隐层节点传递这次变化，再用原网络计算预测差。两边这层之后都还有非线性，全部 250 对都满足这个条件。

## 两种钢的结果

每折有 50 对冻结模型。表中先让每个成员用自己的三个固定节点解释两种钢，再平均同一折的成员。百分比是三节点的有符号预测差除以完整模型的有符号预测差。这两种钢在外层第 0 折留出，解释节点的选择只使用各成员的训练钢样。

| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| mb-steels-005 | +17.93 MPa | +2.37 MPa | 13.2% | +48.16 MPa | +4.69 MPa | 9.7% |
| mb-steels-020 | +24.31 MPa | +2.85 MPa | 11.7% | +18.50 MPa | +1.56 MPa | 8.5% |

## 三节点的公平比较

分别在每个已冻结成员的训练钢样上，计算各节点沿两个端点连线的积分梯度贡献，按减少完整强度变化的平方误差依次选择 1、3、5 个节点。遇到梯度迅速变化的区间会加密数值积分，所有成员在训练材料上都通过“各节点贡献之和还原原始变化，相对误差低于 0.5%”的核查。节点编号在不同训练成员之间可以不同，同一成员对所有测试钢样和两种实际配方改动使用同一组编号。所有报告的三节点 MPa 均重新运行原网络得到，计算使用原节点激活、原层宽和原下游权重。这个选择给出可复用的一组节点，没有穷举所有节点组合。

设低、高当量的第一层状态分别为 L、H。分别计算只把三个节点从 L 换到 H 的输出增加量，以及在完整 H 中把同三个节点换回 L 的输出减少量。两者的平均给出表中的三节点贡献。这相当于让选中三节点和其余节点各先变化一次，再对顺序求平均，避免将非线性交互全部记到先变或后变的那一组。全层变化使用同一对端点。只移动三个节点时保留的是完整配方变化传到这三个节点上的那一部分。

跨折误差按每折测试钢样上的三节点预测差与完整预测差的残差计算。相对均方根误差等于残差向量长度除以完整变化向量长度，越低越好。百分数接近 100% 表示幅值还原较弱。按五折等权统计，避免把同一件钢在 50 个成员中的重复出现当成 50 件独立试样。

| 五折平均，三节点／全模型的还原误差 | KAN | MLP |
| --- | ---: | ---: |
| Ni 替 Fe，相对均方根误差 | 71.4% | 69.7% |
| Ni 替 Fe，平均绝对误差 | 31.8 MPa | 36.9 MPa |
| 同一组节点移到 C 替 Fe，相对均方根误差 | 86.7% | 93.5% |
| 同一组节点移到 C 替 Fe，平均绝对误差 | 31.2 MPa | 37.2 MPa |

在 Ni 路线上，KAN 相对误差较小的折只有 1 个。按折内留出材料作 4,000 次配对自助重采样，KAN 减 MLP 的五折平均相对误差之差，其 95% 区间为 −4.8 至 +6.1 个百分点。两种网络自身预测变化的尺度不同，所以绝对 MPa 误差的排序可以与相对误差不同。在 C 路线上，五折的相对误差均为 KAN 较小，相应差值区间为 −8.2 至 −4.7 个百分点。区间固定了模型、钢种来源和节点选择，只反映本批测试材料的抽样波动。单独考察升降方向，在两种完整模型的变化量绝对值均至少为 1 MPa 的相同材料上，Ni 路线三节点与各自完整模型的方向一致率为 KAN 87.8%、MLP 83.0%，换成 C 路线为 90.6%、82.8%。

改变节点预算也会改变排序。Ni 路线上，将预算从三节点提高到五节点，KAN、MLP 的平均相对误差分别降至 59.5%、61.4%。选随机三个节点则为 91.9%、97.2%。KAN 第一隐层宽 6–204 个节点，MLP 宽 32–320，同一对模型里 KAN 均较窄。如果改为各取本层 10% 的节点并向上取整，Ni 路线 KAN、MLP 的误差为 57.6%、42.1%，C 路线为 81.0%、76.1%。每个成员固定三个节点时看到的迁移优势有明确的预算条件。

还检查了**这些节点本身能否准确读出镍当量**。只用按强度变化挑出的同三个节点，五折留出 R² 为 KAN 0.534、MLP 0.653。若重新选三个最能恢复真实配方镍当量的节点，R² 提高到 0.849、0.888，但这组三节点对 Ni 路线强度变化的相对误差也升至 93.1%、97.3%。一个能识别钢种成分的节点，不一定承担该次配方改动引起的强度变化。[节点编号、读数误差、干预结果和随机对照](../benchmarks/steel-equal-nodes-20261112/summary.json)

## 解释能否跨配方复用

镍当量为 Ni + 30C + 0.5Mn，各元素按质量百分数计量。同样的 +1 点也可通过增加 1/30 个质量百分点的 C、等量减少 Fe 实现。这个对照从原始成分开始重新计算所有模型输入，沿用在 Ni 替 Fe 时挑出的三个节点。因而两种配方实现方式的结果可以区分“网络识别出一个共同的成分坐标”和“网络按照同一强化规律响应”。该公式原用于不锈钢焊缝组织图的奥氏体稳定倾向。[镍当量的冶金出处](https://pmc.ncbi.nlm.nih.gov/articles/PMC7940414/)

钢 005 上，两种完整网络对 Ni 替 Fe 均预测上升，而对 C 替 Fe 预测分别为 −58.31、−145.69 MPa。钢 020 上，对 C 替 Fe 分别为 −7.79、−53.19 MPa。两种路线保持了相同的镍当量差，改变的实际配方不同。钢 005 的起始 C 约 0.010 wt.%，所以这次 C 增量相对于其原始碳含量并不小。

另外检验了在同样三个强度节点上，**输入中有明确物理定义的部分能否重复计算**。把普通成分描述符与 ROOST 学习表示分开，分别在配方改变前后的背景中求普通描述符对这三个节点的变化量，再按前述双向干预换算成对应的 MPa。KAN 的第一层为逐输入一元函数之和。给定这些描述符的前后取值，就能逐项计算对节点的变化并相加。MLP 也获得完整的节点参数，给它同一组描述符取值，并在所有成员训练钢样背景上平均它的精确非线性响应，以此固定一套可迁移的估计。最后用每件留出钢的实际其余输入重算，对照这套估计。两种网络的下游均保留该钢样真实的模型状态。

对普通成分描述符这部分路径，KAN 五折的平均绝对贡献为 1.72 MPa，MLP 为 1.61 MPa。只依据这些描述符的前后取值复用解释，和每件钢完整背景下重算的结果相比，KAN 的平均绝对误差低于 0.001 MPa，MLP 为 0.81 MPa。精确性指该组输入进入三节点、再经过该钢样下游网络的这部分预测。MLP 代入实际其余输入同样可以精确重算，使用固定训练背景才产生上述迁移误差。

可以再具体到一个有定义的描述符。用原子分数加权计算各元素价电子数相对合金平均值的平均绝对偏差。Ni 替 Fe 后，钢 005、020 的该值分别增加 0.01785、0.00792 个电子／原子。上次固定的 KAN 成员中，它通过同三个节点的贡献分别为 −0.65、−0.12 MPa，用同一组样条可逐件重现。配对 MLP 在实际两种背景中为 −0.06、−0.35 MPa，改用训练背景固定响应得到 −1.69、−0.45 MPa。另一个具名量原子尺寸失配 δ 在这两种配方中变化很小，KAN 五折经此路径的平均绝对贡献约 0.003 MPa。材料物理含义来自输入量的定义，贡献的大小和正负仍须从各模型及具体钢样检验。

## 前一次的模型内部读数

在相同第一隐层也原样重做了上一轮的操作。在各自模型内部，用训练钢样把多节点读数标定成镍当量，沿与该读数共同变化的训练方向，在每件钢的原位置两侧各移动半点。两种模型内部读数均恰好相差 1 点，但两端没有对应到同一张物理配方。两种检验各自只用训练数据选节点。[前一次方法与末层结果](steel_strength_intermediate_20261112.md)

在该折 50 个成员的平均结果中，钢 005 的 KAN 三节点解释 +2.69 MPa，完整模型为 +3.46 MPa。MLP 对应为 +18.90 与 +42.91 MPa。钢 020 的 KAN 对应为 +4.65 与 +13.00 MPa，MLP 为 +14.18 与 +30.73 MPa。跨五折的三节点相对还原误差为 KAN 62.4%、MLP 54.7%。上一轮深层读数相差 1 点时的 KAN +21.1 MPa，是另一位置、另一干预的平均响应。这里从配方以 Ni 替 Fe 的完整 KAN 在五折的平均变化分别为 −6.2、−0.2、−10.0、−6.5、−6.9 MPa，两个指定钢样各自的预测仍然上升。物理配方的当量差、隐层中标定的当量差、某种钢的预测强度差需要分别报告。

## 物理验证的边界与复现

312 件钢各有一条实测屈服强度，数据没有同一钢、同一热处理下两张干预配方的配对实验。为了检查有多少近似实测对照，在每折留出样本中寻找元素 Ni 与镍当量都增加 0.75–1.25 点、其余非 Fe/Ni 元素的质量百分数绝对差之和不超过 1 点的配方。按其余成分距离优先配对，每件钢最多用一次，选择不看强度。五折共只有一对，038 到 016，实测差 −114.8 MPa，Ni 与镍当量分别增加 0.910 和 0.909 点，其他成分差共 0.513 点。完整 KAN、MLP 分别预测 −16.7、+103.3 MPa。如此稀少的样本无法验证两种网络的强度变化是否符合实际机制。[Matbench 钢数据定义](https://hackingmaterials.lbl.gov/matminer/dataset_summary.html#matbench-steels)

重算了冻结网络实际使用过的全部 186 列输入，包括 87 个 matminer 描述符和 99 个 ROOST 特征。用 312 张原配方复算时，这两组的逐值最大绝对误差分别低于 7×10⁻¹³、9×10⁻⁷。两套 ROOST 采用归档上游版本的权重和特征提取实现。三节点干预针对原始网络输出。对两件指定钢核对过正式基准的异常预测后处理，完整配方响应在表中显示的精度下相同。[上游 MatterVial 实现](https://github.com/rogeriog/MatterVial/tree/f58652097cebe96f383f17aa6798f4364e99564e) · [逐成员及逐折汇总](../benchmarks/steel-equal-nodes-20261112/summary.json)
