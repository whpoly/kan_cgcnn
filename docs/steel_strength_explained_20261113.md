# 钼的成分差能解释 KAN 的多少强度预测

钢 073 和 042 的实测屈服强度分别为 1233.3 和 1502.0 MPa。对这两件留出原样，KAN 预测相差 **+228.0 MPa**。沿所有隐藏层回溯到原始输入，再把有明确公式的描述符拆回真实元素质量分数，其中 **+183.4 MPa（80.4%）** 可以追溯到钼的成分差。MLP 用同一算法得到 **+76.1 MPa**，占它自己 +80.4 MPa 预测差的 **94.7%**。此前的 8.0% 只计入了三个第一层节点收到的全部信号。两个数回答不同的问题。

## 真实配方、材料量和最后的 MPa

钢 073 → 042 的 Mo 从 3.033 升至 5.082 wt.%，Fe 从 68.228 降至 66.284 wt.%。除 Fe、Mo 外的所有元素质量百分比差绝对值合计 0.146 个百分点，其中 Cr 低约 0.117 个百分点，C 高约 0.020 个百分点。两件钢都在第 3 折留出，以下先计算每一对冻结模型的原始响应，再平均 50 个成员。这个例子最初从十对近单元素成分差的原样中，根据模型对实测强度差的表现选出。[原始选例和全部十对候选](steel_molybdenum_observed_case_20261113.md) · [Matbench 钢数据说明](https://hackingmaterials.lbl.gov/matminer/dataset_summary.html#matbench-steels)

| 073 → 042 的预测差来源 | KAN，MPa | MLP，MPa |
| --- | ---: | ---: |
| 钼质量分数差，经能够逐项验算的描述符传入网络 | **+183.36** | **+76.13** |
| 其他元素在上述描述符中的贡献合计 | +13.33 | +15.67 |
| 其余具有名称、但未进一步拆到元素的描述符 | +24.45 | +6.26 |
| ROOST 学习表示 | +6.83 | −17.69 |
| **完整模型预测差** | **+227.97** | **+80.37** |
| **实测屈服强度差** | **+268.70** | **+268.70** |

对 KAN，其他元素的 +13.33 MPa 主要来自 C 的 +22.10 和 Cr 的 −8.81 MPa。所有元素以 Fe 为余量记账。这样，钼浓度的增量、其他溶质的增量都能对应到实际成分，同时保留质量分数总和为 100% 的约束。两种模型的强度差绝对误差分别为 40.7 和 188.3 MPa。+183.36 MPa 相当于实测差幅度的 68.2%。这个比值比较的是大小，热处理、组织和析出物的独立实验数据仍是确定实际强化机理所需的证据。

## 在 KAN 里，钼对应的 +183.36 MPa 来自哪里

| 钼质量分数差通过的原始输入 | KAN 贡献，MPa | MLP 贡献，MPa |
| --- | ---: | ---: |
| 钼原子分数这一列 | +32.03 | +15.44 |
| 组成元素熔点的加权均值、平均绝对偏差 | +40.01 | +20.92 |
| 元素价电子数及未占据价态的统计量 | +54.51 | +18.34 |
| **这三类输入合计** | **+126.55** | **+54.70** |
| 钼对其余已验算描述符的贡献 | +56.81 | +21.43 |
| **钼路径合计** | **+183.36** | **+76.13** |

仅表中前三类输入就占 KAN 完整预测差的 **55.5%**。价电子一行汇总了 16 列具有非零贡献的相关统计量，包括不同轨道的占据和未占据数。它们是原网络的不同输入列，不能据此推断有 16 个独立强化机制。

其中两个中间量可以直接由元素数据表和原配方算出。成分加权的元素熔点均值由 **1894.86 K 升至 1910.01 K**，元素熔点相对于该均值的平均绝对偏差由 **153.41 K 升至 175.65 K**。这两项整个描述符的变化在 KAN 中分别对应 +19.37 和 +24.86 MPa。把其中与钼成分差对应的部分单列，分别是 **+17.66 和 +22.36 MPa**，未四舍五入的和为 +40.01 MPa。这里用的是各组成元素的熔点数据。实验没有测量这两件合金的熔点。另一个可核对的量是元素未占据价态数的平均绝对偏差，由 0.6380 升为 0.6724，仅这一列里的钼路径就贡献 +17.37 MPa。[Magpie 元素统计量的定义](https://www.nature.com/articles/npjcompumats201628) · [逐描述符原值及有符号贡献](../benchmarks/steel-all-input-paths-20261113/summary.json)

### 为什么 MLP 的净占比反而更高

MLP 的钼项是 +76.13 MPa，ROOST 项是 −17.69 MPa。相反方向的项会缩小完整预测差，因而有符号净占比可以很高。另用一个避免这种抵消的口径，先将同一“元素—描述符”路径在 50 个成员中取有符号均值，再对每项取绝对值求和。未拆到元素的每列也各取一次绝对值。钼路径在这个总量中占 **KAN 59.1%、MLP 44.4%**。若把取绝对值提前到成员平均之前，结果是 **55.5%、48.7%**。这两个指标都在描述符层面统计，内部已加总全部隐藏节点。

## 换一种分配规则，结论如何变化

- 主结果以元素质量分数为坐标，Fe 是余量，对乘积和比值的两端差使用对称分摊。在同一对原样上，改用分别偏向低端或高端的两种等式分解，KAN 的钼项为 **+183.25、+183.48 MPa**，MLP 为 **+76.07、+76.19 MPa**。
- 改以原子分数为坐标、仍用 Fe 作余量，钼项为 KAN **+172.05 MPa（75.5%）**、MLP **+72.74 MPa（90.5%）**。排除元素分项绝对值之和超过该描述符净变化 5 倍的项，主坐标下的两个钼项为 +182.93、+77.63 MPa。
- 逐成员检验“只用钼项后，误差小于该成员完整预测差的一半”，为 KAN **45/50**、MLP **25/50**。成员共享实验材料，这里的重复对应不同训练结果。
- 在原有 41 对按全成分匹配的高低钼钢样中，各对的其他元素可以同时发生较大变化。仅用钼项达到上述一半误差门槛的为 KAN **8/41**、MLP **9/41**。在十对近单元素候选中，只取各对变化最大的非铁元素，对两模型分别是 **2/10、3/10**。073 → 042 的 80.4% 是具体成分对照的结果。

## 全部 312 件钢样能用哪些量来概括

再用一个透明的加和公式近似完整网络输出。每个外层折仅用训练钢样上已有模型的输出，在 23 个成分或材质量中逐步选择三个变量。允许每个变量有一条分段直线，最多三个内结点，取训练样本中实际出现的四分位点。两种模型在联合选择时等权，系数分别标定。**五折均依次选出 Ti、C、Co 原子百分比**。允许 KAN 和 MLP 各自独立选择，五折也得到相同结果。每折的公式都可写成

$$\widehat{\sigma}=b+f_{\rm Ti}(c_{\rm Ti})+f_{\rm C}(c_{\rm C})+f_{\rm Co}(c_{\rm Co}).$$

| 五折等权、只在各自留出钢样上计算 | KAN 的三变量公式 | MLP 的三变量公式 |
| --- | ---: | ---: |
| 对完整网络原始输出的 R² | **0.597** | **0.560** |
| 对基准正式预测（含原有异常值后处理）的 R² | **0.597** | **0.593** |
| 只比较两边都未经后处理的 303 件钢，对原始输出的 R² | 0.594 | 0.589 |
| 对实测屈服强度的 R² | 0.530 | 0.529 |
| 对实测屈服强度的平均绝对误差，MPa | 156.0 | 156.1 |

这个 R² 表示被三条曲线概括的**样本间预测方差**。例如，数据中 Co 的下、上四分位数分别取到 0.0095 和 12.8972 at.% 两个真实读数。单独读取公式里的 Co 项，其差值在 KAN 的五个拟合式中为 +308 至 +337 MPa。这反映本数据集中 Co 所携带的配方信息。对于主要相差钼的 073 → 042，三变量公式分别只给出 −25.6、−26.3 MPa，方向也偏离实测；解释这件事需要前面的全网络钼路径。

## 复算方法

1. 对每个冻结成员，只对已记录的真实钢样计算网络响应。先用已训练边函数的两端差和各层差商，把完整预测差逐层分到原输入描述符。KAN 与 MLP 使用同一端点分配原则，全体描述符的 MPa 加总还原完整预测差。在这次运行的训练、留出配对上，最大加和误差低于 $5\times10^{-12}$ MPa。逐件回放留出预测，与原存档的最大偏差低于 0.001 MPa。
2. 用实际原子分数、元素质量和 Magpie 元素数据表，重建 72 个原始输入列。包括有记录的元素原子分数、元素属性的均值和平均绝对偏差、价电子轨道统计、组成范数，以及 Yang 原子尺寸失配。逐列核对 312 件原样，与存档值的最大绝对数值偏差为 $2.3\times10^{-12}$。相分数、析出物和晶体缺陷没有进入这批核查。
3. 对定义可复算的描述符 $x_k$，把两个原样之间的 $\Delta x_k$ 拆为各实测元素成分差对应的项 $\Delta x_{k,e}$。例如 $\bar T=\sum_i c_iT_i$。质量分数转原子分数时使用原物料两端的摩尔量。对乘积使用恒等式 $\Delta(uv)=\bar u\Delta v+\bar v\Delta u$，比值则由相应的乘积等式求解。元素质量坐标中的 Fe 对应所有非铁元素的平衡项。全过程只使用两个原样的数值，未组成新的钢配方。
4. 若原网络中 $x_k$ 的有符号贡献是 $G_k$，其分给元素 $e$ 的份额为 $G_k\,\Delta x_{k,e}/\Delta x_k$。对几乎不变的描述符保留其原网络净项。未解析的热力学模型、堆积描述符等与 ROOST 分别留在剩余项。分配给元素的值依赖约定，前述质量坐标、原子坐标和两端权重是对这种依赖的实际检验。
5. 全局三变量公式只用当折训练预测拟合。候选变量包括钢任务已登记的 16 个成分或物理坐标，以及 Al、Si、Nb、V、W、Mn、N 原子百分比。每步选择使标准化训练误差最小的变量。分段线性基函数中心化后使用固定岭惩罚 $0.005\,n_{\rm train}$。公式的原始单位系数、结点、有效范围、留出钢样 ID 和预测均已导出。
