# 从 KAN 原生样条中找材料中间量

2026-11-12。分析对象是已训练的两组正式模型。声子任务用 1,265 个晶体预测声子态密度最后一个峰的位置，钢任务用 312 种钢的名义成分预测屈服强度。每个任务包括五个外层折，每折 50 对训练样本相同的 KAN 和 MLP。声子使用 MM + MatterVial 特征库，钢使用 396 个候选描述符的 SHAP Top-50 实验。所有模型权重固定。[声子数据定义](https://hackingmaterials.lbl.gov/matminer/dataset_summary.html#matbench-phonons) · [钢数据定义](https://hackingmaterials.lbl.gov/matminer/dataset_summary.html#matbench-steels)

上一轮预先给出键长、体积、碳氮含量等物理量，再用隐藏激活回归这些量。它回答了网络内部保留了哪些材料信息。这次问的是，**能否从原网络直接取出一个由具名材料输入计算的量，在换材料背景后复算它对节点的贡献，并追到最终预测的变化**。分析中的“中间量”是相对于一个参考材料的部分节点响应，单位是隐藏激活。传播到输出后才有 cm⁻¹ 或 MPa 的单位。[上一轮物理量读出](phonons_steel_physical_intermediates_20261112.md)

## 如何找到中间量

1. 对每对模型，取双方实际使用、定义可查且在训练集中有足够变化的描述符。范围包括元素原子分数、半径、价电子数、局部配位、原子堆积等。钢的两个模型使用相同的输入前缀，声子的两个模型可从同一特征库选取不同前缀，因此搜索限于交集。匿名嵌入仍参与原预测和背景计算。这个范围决定了哪些物理量有机会被命名。
2. 在固定抽取的 96 个成员训练样本上，逐条计算把某个输入置为训练中位数时，接收节点改变多少，再乘以原预测对这个节点的局部梯度，取乘积绝对值的平均。每个输入先看它在各自网络中得分最高的节点。综合两边的名次选择首个输入，然后在对应节点按双方名次补足三个输入。已选输入与新输入的训练相关系数绝对值须小于 0.95。这一步使用模型预测对输入的响应，外层性质标签只用于最后评价预测误差。
3. 取一个真实训练材料作参考。它的三个输入在按训练 10%–90% 分位区间缩放后，距离三项中位数组合最近。设三项输入为 $I$，参考值为 $a$，网络的输入缩放为 $T_i$，第 $j$ 个节点的原生样条为 $\phi_{ij}$。直接从冻结权重取出

$$
q_j(x_I)=\sum_{i\in I}\big[\phi_{ij}(T_i(x_i))-\phi_{ij}(T_i(a_i))\big].
$$

其余输入取任一背景值，这个 $q_j$ 都恰好等于仅把所选三条输入边从参考值换到当前值时，第一层节点 $h_j$ 的变化。每条曲线由原来的 8 个三次 B 样条系数、结点和输入缩放确定。梯度只参与筛选，公式和后续干预使用原网络前向计算。[本项目样条实现](../scripts/standalone_kan_models.py) · [KAN 原论文](https://arxiv.org/abs/2404.19756)

同一组输入在 MLP 激活后的节点上产生 $\sigma(b+w_I^\top [T_I(x_I)-T_I(a_I)])-\sigma(b)$，其中 $b$ 为当前背景配上参考输入时的预激活。知道每个材料的 $b$，MLP 也能精确计算。给定三个输入而省略背景时，我们允许 MLP 使用同时依赖三项的非线性函数，取原生响应在全部训练背景上的平均。另计算一个使用全部留出背景的最优平均值，作为这种固定函数的误差下界。

## 哪些量进入了模型

下表固定采用两个任务各自的第 0 折、第 0 个成员。跨成员的重复情况见下一节。

| 任务 | 第一层中间量 | 在该成员中怎样读曲线 |
| --- | --- | --- |
| 声子，$h_{17}$ | **元素尺寸与价电子响应**。组成元素的最小共价半径、价电子数极差、p 价电子比例各贡献一条样条。 | 最小半径在 71 pm 的参考点附近变化较小，较大半径处该边响应下降。价电子数极差从 5 增到 15 时，该节点沿此路径传到最终峰位的变化中位数为 +0.036 cm⁻¹。 |
| 钢，$h_{23}$ | **Mo 含量、价电子数离散度与堆积团簇成分距离的响应**。离散度为成分加权的价电子数平均绝对偏差。距离取当前成分到最近一个满足高效堆积条件的参考团簇成分的距离。 | 分别只改变一条边，将 Mo 从 0.933 增到 2.450 at.%、离散度从 0.565 增到 0.726、成分距离从 0.0458 增到 0.0600，留出钢样的屈服强度预测变化中位数依次为 +19.36、−19.06、−13.10 MPa。 |

这些区间取自该成员的训练四分位数。计算时只改变所选节点收到的这条边，其余节点和边保留该留出样本的原激活。三项结果各自对应一次独立干预。钢的堆积距离是由名义成分计算的描述符，实测组织、析出物和热处理条件未进入这一任务。[matminer 堆积描述符定义](https://hackingmaterials.lbl.gov/matminer/matminer.featurizers.composition.html#matminer.featurizers.composition.packing.AtomicPackingEfficiency)

## 同一条公式换背景后能否复算

把同一留出材料的三个输入作为一组，依次配到本折每一个留出材料的其余输入上。误差用 RMS 误差除以真实节点变化的 RMS，0 表示完全复现。逐成员计算后先取每折 50 个成员的中位数，再对五折等权平均。真实材料行单独计分。交叉组合检验网络如何计算，其中的部分描述符组合可能无法由真实材料同时实现。

| 留出指标 | 声子 KAN | 声子 MLP | 钢 KAN | 钢 MLP |
| --- | ---: | ---: | ---: | ---: |
| 固定三输入函数，相对误差，全部交叉背景 | 0 | 74.9% | 0 | 41.3% |
| 固定三输入函数，相对误差，仅实际材料行 | 0 | 69.1% | 0 | 38.7% |
| 允许用留出背景求最优固定函数，相对误差下界 | 0 | 74.7% | 0 | 41.0% |
| 每条曲线压缩为两段直线，相对误差，全部交叉背景 | 26.6% | 75.0% | 40.1% | 42.2% |
| 三项加训练常数，预测整个节点的 $R^2$ | 0.043 | 0.029 | 0.233 | 0.281 |
| 三项同时置回参考值，最终预测的绝对变化 | 1.86 cm⁻¹ | 1.03 cm⁻¹ | 6.60 MPa | 16.64 MPa |
| 相同三项改在四个随机节点，最终预测的绝对变化 | 0.40 cm⁻¹ | 0.06 cm⁻¹ | 1.69 MPa | 1.55 MPa |

表中 KAN 的零是加法结构的恒等式。另用原网络对每个成员显式跑了 32 个不同材料的交叉配对，每项任务、每种架构各 8,000 次。使用独立的 SciPy B 样条实现，仅从保存的 KAN 系数与三个物理输入复算，对实际节点变化的最大绝对误差低于声子 $1.87\times10^{-6}$、钢 $1.01\times10^{-6}$。MLP 补回每个接收材料的背景项后，同一核验的最大误差分别低于 $5.36\times10^{-6}$、$1.45\times10^{-6}$。

简单公式也有可量化的近似代价。若每条 KAN 边只保留一条原始物理坐标上的直线，组响应误差升至声子 42.0%、钢 67.0%。用训练中央 80% 的 17 个分位点拟合一个折点、在全部留出材料上计分，可得到表中的 26.6%、40.1%。保留原生曲线时两项任务都能精确复算。折点是函数近似参数，其位置尚无独立相变或强化阈值的证据。

## 三条输入边最终改变了多少预测

以固定钢成员按 ID 排序的第一个留出样本 `mb-steels-003` 为例。相对于参考钢 `mb-steels-091`，Mo、价电子数离散度、团簇成分距离对 $h_{23}$ 的贡献依次为 **−0.11287、−0.14547、−0.02669**，合计 **−0.28503** 个激活单位。只把此节点上的这三条边置回参考值，原模型给出 1,856.86 MPa，恢复三条边后给出 1,839.87 MPa，净变化 **−16.98 MPa**。沿后续网络拆开，训练集选中的三个输出通道分别贡献 −6.49、−7.12、−1.67 MPa，其余通道合计 −1.70 MPa。样本实测屈服强度为 1,736.3 MPa。这个数值反映了已训练模型内部的一条路径，材料强化机制的验证需要独立材料证据。[原生曲线和系数](../benchmarks/physical-edge-discovery-20261112/steel/fold-0/member-00.json) · [输出路径](../benchmarks/physical-edge-discovery-20261112/steel/fold-0/paths/member-00.json)

同一规则选出的晶体 `id1` 则体现了抵消。三个输入值依次为 84 pm、12 和 0.2222，对 $h_{17}$ 的贡献为 −0.00509、+0.00960、−0.00396，合计仅 +0.00055。置回参考值前后峰位预测都约为 631.162 cm⁻¹，差异小于 0.001 cm⁻¹。这个成员在 253 个留出晶体上的三边干预平均绝对效应为 0.301 cm⁻¹。已找到的函数可以解释变化很小的样本。[声子原生曲线和系数](../benchmarks/physical-edge-discovery-20261112/phonons/fold-0/member-00.json)

在全部成员上，把三条边产生的预测变化继续分配到末层原生通道，仅保留训练样本上最有解释力的三个通道，不重新拟合权重。对这次局部干预所导致的真实输出变化，声子 KAN / MLP 的相对 RMS 误差为 **31.2% / 80.8%**，钢为 **54.8% / 84.6%**。如果只用一个训练系数把节点中间量换算成输出单位，误差分别是声子 71.3% / 66.2%、钢 91.5% / 46.9%。从激活单位换到物理单位时，后续非线性和材料背景仍然重要。

## 用多少个末层项可以近似完整预测

另从完整预测出发，两种架构均可精确拆成训练均值加若干个原生输出项。KAN 读取通往输出的样条，MLP 将末端连续的线性层合并，读取最后一个非线性层各节点的加权贡献。每次在训练集上选择最能减小重建平方误差的原生项，固定其权重。每个成员单独选项，再平均成集成。下表 $R^2$ 衡量与各自**原始集成预测**的一致性。

| 每个成员保留的末层项 | 声子 KAN | 声子 MLP | 钢 KAN | 钢 MLP |
| --- | ---: | ---: | ---: | ---: |
| 3 项 | 0.824 | 0.403 | 0.720 | 0.411 |
| 5 项 | 0.949 | 0.554 | 0.865 | 0.549 |
| 10 项，上限为实际宽度 | 0.998 | 0.774 | 0.975 | 0.707 |
| 各自末层宽度的 25%，向上取整 | 0.896 | 0.924 | 0.938 | 0.856 |
| 全部 | 1.000 | 1.000 | 1.000 | 1.000 |

固定三项的结果在两个任务的每一折都偏向 KAN。两组 KAN 的末层整体更窄，配对成员中末层完全同宽的数量为零。达到训练 $R^2$ ≥ 0.90 时，声子两者所需项数的折中位数平均为 4.8 / 17.1，钢为 7.4 / 22.5。相应项数占末层的比例为声子 33.9% / 24.8%、钢 27.3% / 26.9%。因此，固定项数的优势适用于这批实训模型，网络宽度和架构的各自作用尚未分离。

对真实标签，五项近似的声子 MAE 为 68.36 / 215.50 cm⁻¹，完整模型为 28.23 / 28.76 cm⁻¹。钢的五项近似为 118.64 / 161.71 MPa，完整模型为 84.96 / 86.44 MPa。这里的钢 MAE 沿用原 MODNet 成员的种子和异常输出处理，原网络保真度及路径干预使用处理前的数值。保留五项足以显示主要输出贡献，获得原预测精度仍需要其余通道。

## 重现

在项目根目录使用训练环境运行以下三步。按原模型、数据、选择文件及输出归档的 SHA-256 核验重放，每个成员保存独立的 JSON 和 NPZ。固定示例按折号、成员号和材料 ID 选择。五折划分是统计汇总单位，同折 50 个成员共享不少训练样本。

```powershell
$modelPython = "$env:USERPROFILE/.conda/envs/modnet-v013-mattervial/python.exe"
foreach ($dataset in "phonons","steel") {
    & $modelPython scripts/discover_physical_kan_responses.py --task $dataset
    & $modelPython scripts/audit_physical_kan_paths.py --task $dataset
}
& ./.venv/Scripts/python.exe scripts/report_physical_kan_responses.py
```

所有折的中间量、输入入选次数、实际输出变化和压缩结果均可从逐成员归档追溯。[完整数值汇总](../benchmarks/physical-edge-discovery-20261112/summary.json) · [输入筛选与样条提取](../scripts/discover_physical_kan_responses.py) · [原模型干预和路径核验](../scripts/audit_physical_kan_paths.py) · [统计与作图](../scripts/report_physical_kan_responses.py)
