# phonons 物理特征模块：预先固定的小规模试验

## 范围与数据边界

本轮先检验 16 个物理描述符能否生成有用的 4 个额外特征。只使用 Matbench phonons 外层第 1 折的 1012 个训练样本，保留原先记录的五个内层划分。新运行器不载入外层测试数据。源数据为 `benchmarks/official-aligned-20261021/matbench_phonons/fold-0/official-train-moddata.pkl.gz`。

每个内层训练部分重新计算目标相关 NMI 并执行 MODNet 原生相关性/冗余排序，取 190 个基础描述符；复用原缓存中与目标无关的 cross-NMI 表。该冗余表是固定先验，并未在本轮重新按内层训练样本计算。物理描述符按先验指定，不根据外层误差挑选。缺失/非有限数值固定填零，MinMaxScaler 仅拟合内层训练部分。所有变体共享同一基础特征排序、输入缓存、划分和种子。

本轮固定单一主干，而不是重新运行整套官方 GA。主干与基础特征数来自此前 phonons 内层选择的配置：190 输入，隐藏层 96/72/36/36，前三层 ELU，第四层及输出层线性。不能将这里的内层验证 MAE 与此前五折、50 成员的外层 benchmark 直接比较。

## 五个模型

| 变体 | 输入与模块 | 所回答的问题 |
| --- | --- | --- |
| MODNet 架构对照 | 190 个内层筛选特征，原主干 | 当前小规模协议基线 |
| 相同物理输入 | 上述特征与 16 个物理描述符去重后的并集，原主干 | 补充原始输入是否已足够 |
| 等参数分组 MLP | 相同并集，再拼接四个分组 MLP 输出 | 同容量可训练特征对照 |
| 分组样条 | 相同并集，再拼接四个分组加性样条输出 | 样条函数类对照 |
| 分组稀疏 KAN | 与样条相同，增加边/组软稀疏约束 | 稀疏归纳偏置是否有帮助 |

四组各含四个描述符，各输出一个数值。所有模块有 **148 个实际参与计算的可训练参数**，没有填充参数。三种模块模型总参数量在每个内层折完全相同。基础 MODNet 和仅追加物理输入的模型参数更少；参数量逐折记录。

- 质量：原子量均值、范围、平均绝对偏差、最大值。
- 尺寸与密度：共价半径均值、平均绝对偏差、密度、每原子体积。
- 局部成键：平均键长的均值和标准差、Voronoi 配位数均值、邻居距离变化的平均偏差。
- 电子性质：电负性均值和平均偏差、价电子数均值和平均偏差。

精确列名与次序保存在 `scripts/physical_feature_modules.py` 的 `PHYSICAL_GROUPS`，并写入运行协议。第一折各内层特征并集的大小允许不同，但同一个内层折所有物理增强变体完全一致。

分组 MLP 为每组 4→6→1，隐藏层 ELU，每组 37 参数。样条与 KAN 为每条输入边 8 个三次 B 样条系数加 1 个线性系数，每组另有 1 个偏置，共 4×(4×9+1)=148。样条网格固定在 [-0.5,0.5]，5 个区间；样条分支边界截断，线性分支不截断。无 LayerNorm。

样条和 KAN 都有二阶系数差分平滑惩罚（强度 0.001）；KAN 另有平均边范数加 0.25 倍平均组范数的软稀疏惩罚（强度 0.01）。两项都乘以内层训练目标的标准差以匹配目标量纲。超参数在本轮固定，仅调学习率。软惩罚不保证产生精确零权重。

这两个模块属于同一个分组加性函数类，区别是稀疏正则。组内无显式乘性交互，跨组交互由后续 MODNet 完成。四个中间量也不等于整个预测器都能写成物理公式。

## 训练、选择与审计

- 两个学习率：0.0005、0.001；两个基础种子：20261023、20271023，各加内层折索引。
- 五变体 × 两学习率 × 两种子 × 五内层折 = **100 次训练**。
- Adam，原目标尺度 MAE，batch size 32，最多 800 epochs。
- 以训练 MAE 早停：patience 30，min_delta 0.001，不恢复最佳权重。以 MAE 而不是含惩罚项的总 loss 监控，可避免不同模块正则项影响停止定义。
- 所有模型按种子共享基础 MODNet 权重初始化；三个模块模型额外输入到第一层的权重也配对；训练前重新设置随机种子。
- 每个变体按全部五个内层折、两个种子的平均验证 MAE 选择一个学习率，平分时选较小学习率。
- 报告单成员验证均值、两个种子预测平均后的逐折验证 MAE、参数量、训练时间和候选搜索累计时间。时间是本机并发负载下的测量，累计成员分钟不等于墙钟时间。
- 保存每个模型、验证预测、样本 ID、训练轨迹、缩放器与描述符清单；协议包含源代码、输入数据和环境版本指纹。
- 一轮单 epoch 的 50 次训练 smoke 只验证程序流程，不构成性能结果。

结果位置：`benchmarks/phonons-physical-pilot-20261023/`。启动脚本：`scripts/start_phonons_physical_pilot.ps1`。与仍在运行的第二轮三数据集任务使用不同目录，后者源代码与协议不作修改。

## 解释范围

本轮只用于快速判定是否值得扩展。学习率是在所报告的验证集上选择的，因此结果有选择偏差；不能据此宣称超过正式外层成绩。下一阶段如扩展到全部外层折，所有选择仍须在各自内层完成。已有外层误差分析也只提供探索线索，不能用测试预测拟合融合权重、门控器或筛选样本。
