# phonons：MatterVial 与分组 KAN 的 20 次快速验证

2026-10-26 启动。输出目录：`benchmarks/mattervial-quick-pilot-20261026`。

目的：在小预算下检查去除全部 SISSO 后，MatterVial 输入和分组稀疏 KAN 是否出现值得追加验证的信号。本试验采用简化协议，不是论文训练流程的正式复现；不得与论文五折外层 MAE 30.08 直接相减。

## 数据与四组对照

仅使用第一外层折的 1,012 个训练样本，沿用已有 MatterVial 运行该折的五个内层划分。只复用划分 ID；不复用旧的特征筛选、模型权重或成绩。读取原始 CSV 时扫描文件行，非训练样本在数值转换之前被跳过，不保存或计算它们的目标值。

全部 283 个 SISSO 列在数值转换和特征筛选之前排除。MatMiner 候选池有 2,059 个特征，增强候选池有 4,455 个特征；增强池沿用此前约定的 MatMiner、MEGNet OFM、MVL16/32、ROOST mpgap、ORB 特征组。去掉 SISSO 不代表已经核实所有外部预训练模型的标签来源。

| 组 | 输入 | 网络 |
| --- | --- | --- |
| A | MatMiner 筛选的 256 个输入 | MODNet 96/72/36/36 |
| B | 无 SISSO 增强池筛选的 256 个输入 | 相同 MODNet |
| C | 与 B 完全相同 | MODNet 加分组 MLP 16→4 模块 |
| D | 与 B 完全相同 | MODNet 加分组稀疏 KAN 16→4 模块 |

A/B 参数量相等；C/D 总参数量完全相等，其中物理模块各 148 参数。物理模块使用此前固定的四组、每组四个描述符。四个模块输出与 256 个原始输入拼接后进入主干。KAN 为固定结点三次 B 样条加线性支路和软稀疏约束，并非全 KAN 网络。固定平滑强度 0.001、稀疏强度 0.01，按内层训练目标标准差缩放。

## 预算与筛选

每个内层训练集、每个特征池各拟合一次 XGBoost（100 树、深度 6、学习率 0.1、hist、gain），共 10 次树筛选，不计入 20 次神经网络训练。选择固定 16 个物理描述符，加其余重要性最高的 240 个输入。重要性相同时按名字排序。A/B 分别筛选，B/C/D 严格复用同一筛选与缩放结果。

缺失值按固定零值替换；minmax [-0.5, 0.5] 只拟合内层训练集。没有全局相关性预筛、全局互信息缓存或验证集参与筛选。

第一阶段：4 模型 × 5 内层折 × 1 学习率 × 1 配对种子 = 20 次。

- 初始学习率 0.001，基础种子 20261026；每折种子加内层折编号，四组保持相同。
- 最多 300 epochs，batch 32，Adam，原目标尺度 MAE。KAN 加上述固定正则。
- 统一监视训练 MAE 早停，patience 30、min_delta 0.001，不恢复最佳权重。
- 验证集只用于最终评分与条件扩展；不选验证最佳 epoch。
- 固定相同初始化方式和共享主干初始权重；参数新增部分按固定规则初始化。
- 预算相同指训练次数和最大轮数、批大小及早停协议相同，不强求实际轮数或墙钟时间相同。
- 保存逐折预测、模型、实际轮数、是否碰到轮数上限、参数量、累计训练秒数。

## 在看结果之前固定的扩展规则

MatterVial 信号：B 相对 A 至少 4/5 折 MAE 降低，且五折平均 MAE 降低至少 1%。

KAN 信号：D 相对 C 达到同一条件，且 D 的五折平均 MAE 低于 B。

任一信号成立才将四组一起扩展：学习率 {0.001, 0.0005}、基础种子 {20261026, 20271026}。复用初始 20 个模型，再增加 60 次训练，总计 80 次，不追加特征筛选。若没有信号，完成 20 次后停止快筛。

阶段 80 对每组使用全部五折、两个种子的平均成员 MAE 选择学习率；报告候选分数和逐折、逐种子结果，不把这些选择验证分数解释为独立测试分数，也不把成员 MAE 误称为集成 MAE。

上述 1%/4 折规则是预先声明的计算预算分配规则，不是显著性检验。五个内层折的训练集相互重叠，单个种子也不足以证明初始化稳定性。这批训练数据以前用于探索；这里不是全新盲测。若大量模型达到 300 轮上限，无提升只说明当前小预算下未见改善，不能据此否定方法。

## 运行与验证

启动入口：`scripts/start_mattervial_quick_pilot.ps1`；2 个 CPU worker；独立输出目录。原正式复现任务及其源码保持原状态。

运行状态：`status.json`。第一阶段输出 `stage-20-summary.json`、`stage-20-report.md` 和 `expansion-decision.json`；如扩展则追加 `stage-80-summary.json`、`stage-80-report.md`。`protocol.json` 冻结源码哈希、包版本、划分及训练设置；恢复时拒绝不匹配缓存。

启动前通过 5 个完整性测试：不转换外层标签及 SISSO 值、训练集内筛选与缩放、模块参数与主干初始化配对、扩展规则拒绝单折挑选、合成数据 20 次单轮端到端流程及预测/断点哈希校验。合成测试成绩不是实验结果。
