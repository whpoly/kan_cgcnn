# 钢 073 和 042 的钼含量差，KAN 与 MLP 各解释了多少屈服强度差

**全网络复核**　将全部隐藏层和可复算的原始成分描述符纳入之后，073 → 042 的钼质量分数差可对应 KAN 的 +183.4 MPa，占完整预测差的 80.4%。下文的 8.0% 是此前三个第一层节点的结果。[预测差的完整分解与跨折检验](steel_strength_explained_20261113.md)

钢 073 和 042 的钼质量分数分别为 3.033% 和 5.082%，两件钢的实测屈服强度相差 **+268.7 MPa**。在两者共同留出的第 3 折，KAN 预测 **+228.0 MPa**，MLP 预测 **+80.4 MPa**。两种模型的 50 个成员全部判断对了升降方向。逐个配对比较，48 对是 KAN 的预测差更接近实测差。以下所有材料、成分和强度标签均来自 Matbench 原有的 312 件钢样。[数据集说明](https://hackingmaterials.lbl.gov/matminer/dataset_summary.html#matbench-steels)

## 为什么选这一对

在每个留出折内考察两两原样，找出除 Fe 外质量百分比变化最大的元素。要求该元素相差至少 0.1 个百分点，其余非 Fe 元素的绝对差之和不超过 0.2 个百分点，且不超过主要元素差值的 10%。五折共找到 10 对，分别以 Co、Cr、Mo、Ni 为主，有 6、2、1、1 对。再查看预测结果，实测强度差绝对值达到 50 MPa 且 KAN 预测差的绝对误差小于 MLP 一半的只有 073 → 042。这是从已有结果中挑选的优势案例，10 对候选的正反结果均有保留。[全部候选与选例数值](../benchmarks/steel-observed-molybdenum-20261112/summary.json)

073 → 042 的 Mo 高 2.049 个质量百分点，Fe 低 1.944 个百分点。其余元素的绝对差合计 **0.146** 个百分点，主要是 Cr 低约 0.117 个百分点、C 高约 0.020 个百分点。两件钢同属第 3 折的测试集，每对模型使用相同的训练样本和输入描述符，KAN 对 MLP 的参数数比为 0.963–1.024。名义成分和实测屈服强度可以逐样核查。这批记录缺少相应的热处理和析出相测量，无法从两件钢中分出由钼单独引起的强化量。

| 实际钢样 | Mo，wt.% | 实测屈服强度，MPa | KAN 留出预测，MPa | MLP 留出预测，MPa |
| --- | ---: | ---: | ---: | ---: |
| 073 | 3.033 | 1233.3 | 1263.2 | 1342.3 |
| 042 | 5.082 | 1502.0 | 1491.1 | 1422.6 |
| 两件钢之差 | +2.049 | **+268.7** | **+228.0** | **+80.4** |

## 同样给三个第一层节点

“钼相关节点”和“钼输入本身经过的路径”回答两个问题。前者找出能从激活中共同读出钢中钼原子百分比的三个节点，这些节点也接收别的描述符。后者专门追踪模型的显式钼输入。在看测试钢之前，两种模型都只用成员训练钢样确定节点，各取三个。下游的全部非线性层都参与强度差分解。

| 073 → 042 的模型内部贡献，MPa | 纳入的配对模型 | KAN | MLP |
| --- | ---: | ---: | ---: |
| 三个最能读出钼含量的第一层节点，合计贡献 | 50 | **+18.20** | **+2.75** |
| 钼输入经过所有第一层节点，合计贡献 | 27 | +59.25 | +28.55 |
| 钼输入经过训练时选定的三个第一层节点，合计贡献 | 同一批 27 | **+10.15** | **−4.59** |

50 对中有 27 对把钼原子分数直接作为原始输入，后两行只在这 27 对之间比较。沿三条显式钼路径所得贡献为正的成员，KAN 有 **22/27**，MLP 有 **6/27**。三个能读出钼含量的节点，其总贡献占各自完整预测差的 8.0% 和 3.4%。三节点预算对齐了需要查看的节点数量。此处的 KAN 每条边有八个样条系数，MLP 每条输入边有一个线性权重。这些数字描述网络如何分配预测差。不同选法可能覆盖同一路径，表中各行不能相加。

## 从真实钼含量复算一条曲线

取该折按原顺序第一个使用钼输入的配对成员，以及各模型按训练数据排在首位的钼路径。两端用钢 073、042，再从同折实际测试钢中取钼原子百分比最接近两端中点的钢 022。三件钢的钼含量依次为 1.769、2.357、2.988 at.%。022 仅用于核对同一条边。

KAN 的钼 → 第一层节点 30 有一条自己的函数。在三件钢的原始输入位置，函数值依次为 **0.05748、0.12290、0.13046**。073 直接到 042 的贡献为 **+0.07297** 个节点单位。从 073 到 022，再到 042，两段贡献 **+0.06541** 与 **+0.00756** 之和也是 **+0.07297**。

MLP 的对应节点 92 先把全部输入加权相加，再通过 ELU 激活。将激活后的节点差按原权重和两端激活函数的差商分配给各输入，钼这一项直接算为 **−0.03681** 个节点单位。经过同一个真实钢 022 分两段算，则为 **−0.30138**。如果该项可由只依赖钼含量的一条函数表示，中间点的函数值应在两段求和时抵消。这三个原样已经能检验这个条件。MLP 的激活前加权项仍然可加，完整 MLP 也能用多个节点学习非线性。

对 27 对模型的三个训练选定节点都做这个检查。按各节点在训练钢样上的标准差归一化，直接算和分段算的平均绝对差，KAN 低于 $10^{-15}$ 个标准差，MLP 为 **0.0923** 个标准差。这是对激活后节点的检验。传播到最终 MPa 还要使用该对钢自己的下游响应。[KAN 架构原文](https://arxiv.org/abs/2404.19756) · [本项目的网络实现](../scripts/standalone_kan_models.py)

## 在其余钢样上能重复多少

沿用已有的五折钼含量高低组匹配名单。各折只用训练钢确定高低组、最低钼含量差和成分距离上限，再按全部元素成分匹配该折的真实留出钢。共 41 对、82 件不同的钢。这套较宽的成分匹配与主案例的近单元素条件不同。主案例的整对没有出现在这 41 对中，钢 042 作为其他配对的一端出现一次。

| 检验 | KAN | MLP |
| --- | ---: | ---: |
| 41 对的完整预测差相对实测差的平均绝对误差，MPa | **122.1** | 144.0 |
| 三个能读出钼含量的节点，其贡献与实测差同向 | **35/41** | 27/41 |
| 整个排除主案例所在折后，同一方向检验 | **27/33** | 20/33 |
| 三条显式钼路径还原全部显式钼路径的相对均方根误差，五折等权 | **65.5%** | 73.9% |
| 三个能读出钼含量的节点，在所有留出原样上解码钼含量的 R²，五折等权 | 0.661 | **0.784** |

五个留出折中，KAN 的完整强度差平均绝对误差均较小，三个显式钼路径对全部钼路径的相对还原误差也均较小。这里三条路径的还原仍有较大残差。MLP 的三个物理节点对钼含量本身读得更准。

另有一件接近的真实钢 015。它与 042 符合同一近单元素条件，Mo 为 7.147 wt.%，实测屈服强度 1460.7 MPa，比 042 低 41.3 MPa。按各钢自己的留出预测，KAN 低 5.6 MPa，MLP 高 115.0 MPa。015 属第 4 折，042 属第 3 折，两点的预测使用不同的留出模型。三件钢能核对观测排序，确定最佳钼含量还需要同条件材料实验。

## 如何复核

钼含量的三个节点按训练原样上的三步前向岭回归选取。显式钼路径按训练匹配钢样间的真实输出差选取，每一步保留最能还原全部钼输入路径贡献的第一层节点。两种架构沿用相同的两端差分规则，输入位置、隐藏状态和标签均取自真实钢样。对 KAN，逐输入函数在两个原样上的函数值差直接给出进入节点的贡献。对 MLP，按输入加权差乘以节点非线性的两端差商分摊激活变化。逐层传播得到有符号 MPa。全层各节点的贡献加总与双精度原始输出差的最大偏差低于 $2.1\times10^{-12}$ MPa。原样预测与冻结存档的最大偏差低于 0.001 MPa。
